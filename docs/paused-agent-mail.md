# Mail to a paused agent

When another agent writes to an agent whose provider is paused, Genie saves the
message and sends an automatic reply to its sender:

> Automatic reply from Genie: this agent is paused and cannot respond right now.
> Your message has been saved for them. If you are blocked, ask your user for guidance.

The sending agent also receives this status in its send result, so it can ask for
guidance without polling its inbox or waiting for its own turn to finish.

The reply names no provider error, account detail, or reset time. It does not claim
that the recipient has read or answered the message. Only the recipient's own
acknowledged receive marks the original as read.

Paused means a reported rate-limit pause, retry backoff, a rate-limit gate needing
the person, or an account pause. An idle, busy, stopped, or signed-out agent is not
assumed to be paused. Normal inbox delivery and waking remain the same.

Each agent-to-agent message gets at most one automatic reply. The original and
reply are saved together before either arrival is announced. Automatic replies
cannot generate another automatic reply, including when both agents are paused.
Mail from the person or an app, and an agent's mail to itself, gets no such reply.

The reply is marked as generated by Genie and linked to the original message. It
does not count as the recipient opening a conversation for reply permissions.
