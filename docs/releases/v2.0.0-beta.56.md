# Genie 2.0.0-beta.56

## What's new

### The phone app scrolls
- Every phone screen scrolls inside itself: the dashboard, the chat, files, and the markdown and code viewers. In beta.55 anything below the first screen was out of reach.
- The waiting-on-you strip in chat has a height limit, so the message box always stays on screen.
- On Android the screen shrinks when the keyboard opens.
- On iPhone the back and Disconnect buttons no longer sit under the status bar.

### Menus behave like menus
- **The sidebar and Settings:** both are navigation menus. Items are left-aligned, the current page is marked, and the arrow keys move between items.
- **Tabs, switches and the breadcrumb:** the workspace and agent tabs are real tabs, "By workspace / By status" and "All / Changed" are switches, and the agent breadcrumb is a breadcrumb.
- **Attention dots:** the dots for the Deck, rate limits, Settings and "needs you" also show in the icons-only sidebar. Hover over one, or reach it with the keyboard, to read what it means. The Settings dot names the phone and the date its pairing expires.
- **No ring after a click:** a focus ring now shows only when you move with the keyboard.
- **Rows:** list rows, such as the phone's agent cards, are left-aligned again.

### Tynn sign-in on Omarchy and other Linux desktops
- If the system keyring isn't running when Genie starts, Genie now starts it. Before, it refused your sign-in.
- **If there's no keyring at all,** Settings → Tynn and GitHub show a card to install it. Your system asks for your password; Genie never does. If it can't ask, the card shows the command to run yourself.
- Genie never stores your sign-ins in plain text.

### Agents
- **Mail reaches a busy agent at its next step,** the way your own messages do, instead of waiting for the whole turn to end. Questions you answer reach the agent this way too.
- **Opening an agent no longer starts it.** It starts on its first message, on mail that wakes it, or when you press Start. An agent that hasn't done anything shows as idle, not "Turn 0 · running".
- **Cooling:** for 15 seconds after an agent finishes a turn it shows **Cooling**, then **Idle**. "By status" sorts it with Working, so your list doesn't jump around between turns. Mail and your messages reach a cooling agent straight away.

## Known limitations

- **Untested on real phones:** the phone app is proven on phone-sized test browsers, but not yet in Safari on a real iPhone or with a real on-screen keyboard.
- **macOS** isn't supported right now, and no macOS builds are published.

## How it was verified

- **Tests and CI:** every change merged with its tests failing first, then passing. Main's CI is green on every job, including the real-window smoke on Linux and Windows and both installer builds.
- **Test machines:** the full test suite ran on the Linux and Windows test machines. The real-window smoke ran on the Linux test machine.
- **The phone:** checked with real touch swipes on iPhone and Pixel screen sizes.
- **The keyring:** the full sign-in was run in the real app against a test Tynn on Omarchy: install the keyring, sign in, quit, relaunch, still signed in.
