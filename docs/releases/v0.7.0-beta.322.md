## What’s new

- **A hosted PHP site whose worker dies now comes back.** `php-cgi` had no restart policy, so a site kept 502ing until someone noticed. Genie restarts it, bounded, and stops pretending it is ready.
- **Provisioning MinIO works again.** Docker Hub stopped serving its image to anonymous pulls; Genie now fetches it from the registry that does.
- **Pinning the lists panel no longer shoves the header icons sideways** — it docks under the header instead of reflowing it.
- **Each runtime box on a workspace row opens its own thing.** The dropdown naming them is gone: the top box is background processes, the lower one the Site Manager.
- **Genie OS only shimmers while it is actually working**, rather than the whole time the panel is open.
- **Feedback says which project it landed in**, so a Genie defect raised from a client workspace no longer disappears into that client's backlog silently.
