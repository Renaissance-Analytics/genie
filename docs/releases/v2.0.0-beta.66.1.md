# Genie 2.0.0-beta.66.1

**Each Claude account now shows and uses its own limits, so switching accounts really moves you off a spent one. Leave safe mode works.**

## What's new

### Accounts and limits
- **Every account shows its own usage.** One account's numbers are no longer copied onto your other accounts, so the Accounts panel shows each account's real figures.
- **Each account shows only the limits it has.** An account with no 5-hour limit shows no 5-hour bar, and weekly per-model caps (such as Fable) appear when the account has them. An account Genie hasn't read yet says "Usage unknown" instead of borrowing another account's figures.
- **Switching moves you off a spent account.** After a switch, the limit warning and auto-resume follow the new account, and an agent held by the old account's limit moves to the new one at once.
- **Clearer figures.** Every figure reads "% used", as Claude's own usage page does, and the bars fill and turn amber, then red, as you use more. The switch offer's numbers match the bars.
- **Signing in shows at once.** A finished sign-in is no longer missed by a check that was already running.

### Safe mode
- **Leave safe mode works.** The banner goes as soon as you click, and Genie says "Left safe mode. Automatic starts are back on."

## Known limitations
- A slow but normal "Shut down everything" can still be recorded as an unclean end and start Genie in safe mode next time. Leave safe mode now gets you out with one click; the cause is fixed in a later release.
