## What’s new

- **You can open the upgrade window and close it again.** Closing it used to cancel the upgrade, and cancelling made the window impossible to reopen without starting over.
- **After an upgrade, Genie names every one of its servers that needs reconnecting** — it used to mention only one of the two, leaving your agent inbox quietly disconnected.
- **A port conflict no longer kills the agent inbox channel for the rest of the session.** It retries, like every other transient.
- **Agents hand off the same way.** The protocol now says when to leave a note and what belongs in it.
