## What’s new

- **A hosted `.gen` page can open a WebSocket again — and Vite hot reload with it.** The HTTPS rewriter swallowed every frame over HTTP/2, on every `.gen` site, looking like a dev-server fault.
- **The bundled WebSocket server is Sockudo, and now says so.** It was labelled Reverb, a different vendor’s server. `REVERB_*` variables still work as aliases.
- **Popovers stay on screen.** Ten placements clamped ten different amounts — some ran off the bottom, some off the side. All of them now clamp both axes.
- **Quick capture files an Issue again.** The hotkey was posting to a route that had been retired, so every capture failed silently.
- **A Flow Manager, and a header button that moves only while a Flow really runs.** Flows can be created, and a new one stays off until you turn it on.
- **An agent is Automated or Manual**, and Genie’s nudges are worded for which one it is.
- **An upgrade drains your agents first, then restores what it drained** — instead of restarting things you had deliberately stopped.

## Migration

- The bundled WebSocket host is now `websockets.<workspace>.gen`, not `reverb.<workspace>.gen`. Env vars are aliased, but a hardcoded hostname needs updating.
