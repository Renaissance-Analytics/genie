## What's new

- **beta.1 opened on a screen you could not leave** — and on a cold boot it opened no window at all, while your agents started themselves behind it. Both fixed.
- **Agents no longer start themselves when Genie launches.** They stay stopped, still listed, until you start them. Turn it back on in Settings.
- **Genie opens on the Workflow Dashboard**, and its rows open the agent. Empty workspaces offer Add agent. The Deck keeps what needs you and gives up its agent list.
- **Chat sends.** Typing worked and sending did not; Stop and approvals did nothing. All now work, and a failed send puts your draft back instead of destroying it.
- **The terminal leaves the Floor.** The 2×2 grid is gone; a provider TUI opens in its own window, attached to the agent already running — never a second one beside it.
- **Files, Changes and Activity are real**, and **Lanes** arrive on `L`: every message, thought, tool and edit over the turn, with a drag to filter the stream.
- **macOS builds are paused.** Windows and Linux only for now; the Mac build is coming back.

## Migration

- Genie opens on the Dashboard; the Deck is one ⌘K away. An old `?view=grid` link lands there, or on that workspace if it named one. `⌘B` files, `E` next edit, `/` find.
