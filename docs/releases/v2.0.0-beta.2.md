## What's new

- **beta.1 opened on a screen you could not leave.** Its agent rows had no click handler, the rail changed nothing visible, and the only way out was a ⌘K row.
- **Genie opens on the Workflow Dashboard**, and its rows open the agent. Empty workspaces offer Add agent. The Deck keeps what needs you and gives up its agent list.
- **Chat sends.** Typing worked and sending did not; Stop and approvals did nothing. All now work, and a failed send puts your draft back instead of destroying it.
- **The terminal leaves the Floor.** A provider TUI opens in its own window, attached to the agent already running — never a second one started beside it.
- **Files, Changes and Activity are real.** All three printed only their own name. Activity names the channels Genie cannot see rather than reading as "nothing happened".
- **Lanes, on `L`.** Messages, thoughts, tools and edits over the turn; drag a range to filter the stream. Restart and Agent settings finally appear on the agent screen.

## Migration

- Nothing to do. Genie opens on the Dashboard; the Deck and the grid are each one ⌘K away. Workspaces, panels and agents are untouched.
- `⌘B` opens workspace files, `E` jumps to the next edit, `/` finds in the stream.
