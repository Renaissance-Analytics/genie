## What’s new

- **Nine things an agent does can each have their own sound — or None.** Talking, finishing, asking, running a Flow, reporting from a cron, signalling ready, and three more. All start silent.
- **A cron no longer arrives as you.** A scheduled notice an agent set up was labelled “You” and filed in your own message history; it now says which cron sent it.
- **PHP sites are re-asked how they should be served.** A site stuck on a single-threaded dev server moves to FastCGI when you start or restart it, so one slow request can no longer block every other.
- **A hosted PHP app can read its own service connections.** Genie never told PHP to expose them, so `$_ENV` was empty and apps fell back to a database that may not exist.

## Migration

- Nothing to do. New sounds are all off — turn on the ones you want in Settings → Customization. A PHP site keeps its old server until you start or restart it; Genie does not switch it at launch.
