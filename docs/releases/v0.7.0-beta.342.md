## What’s new

- **Your terminals stop dying all at once.** Genie could start a second terminal host while one was already running; the two collided and took every terminal, worker and agent down with them.
- **A lost terminal host comes back on its own.** It used to try once, lose a race it would have won a second later, and stay broken until someone noticed.
- **Genie notices when its terminal backend is degraded and fixes it.** Checked when you focus the window, so terminals survive restarts again without you doing anything.

## Migration

- Nothing to do. If terminals are currently not surviving restarts, this build repairs that by itself shortly after you open it.
