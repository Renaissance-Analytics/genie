# Genie 2.0.0-beta.66

**Remote access works: your other machines and share links connect through Tynn's relay, no Tailscale needed. The host keeps your agents running through window updates, host updates and quitting the window, and Genie can start when you sign in. Trust is safer, Proof-of-Done asks once, and settings are never lost.**

## What's new

### Remote access
- **Connect to your own machines and to share links without Tailscale.** Every connection goes through Tynn's relay, whatever this machine's role.
- **A host whose relay goes quiet reconnects by itself**, so your machines no longer read offline while they are up. Settings shows when it started reconnecting.
- **Share links work from any of your machines**, and a refusal no longer claims you are signed out.
- **Agents on your machines can mail each other**, even with no window open; mail waits for a machine that is off and is marked received only when the agent can take it.

### Agents keep running
- **Window updates leave your agents running.** An update that only replaces the window keeps the host and its agents going, still streaming.
- **Host updates bring your agents back.** The host finishes what it is doing, swaps itself for the new version, and restores each agent once.
- **Quit the window and your agents carry on**, and a window that closes or crashes can be opened again onto the same running agents.
- **Start at sign-in works:** Launch at sign-in and Start minimised are now kept through every restart.
- **Processes, flows and scheduled tasks get the workspace's database variables after a restart**, even before any window opens.

### Trust and safety
- **Trust can no longer be left on by mistake.** A stale or failed check never leaves a workspace trusted, and a new file is checked the moment Genie acts on it.
- **Untrust stops a workspace's processes and flows**, and Take Over, Codex and agent start check trust each time they act.
- **Proof-of-Done asks once:** one grouped request names each Tynn project and task, with Sign all and Deny all.
- **Approvals that nobody answers expire after 30 minutes**, and both you and the agent are told.

### Settings and workspaces
- **Settings are never lost:** two changes made at the same time both stay.
- **A workspace whose folder is gone is shown as missing**, with Locate folder, instead of disappearing.
- **Rebuilt a machine?** Genie picks up its data folder again and tells you what it could not restore.
- **Clean up works:** Move to .trash and Empty trash show progress, name what failed, and never offer a worktree in use.
- **The workspace bar** holds Terminal, Share and Clean up, and its built-in tabs are icons with tooltips.

### Agents and chat
- **Claude accounts:** sign in and out in the browser, see each account's state, and switch the active account with one click.
- **Agents can create agents**, and the first or only agent is the default.
- **The Fancy Dev Kit is offered to every agent**, on by default, and can be turned off per workspace.
- **The wake cap is each agent's own setting:** a number of wakes an hour, or no limit.
- **Esc takes back a message** still waiting to send, and **a whole question can be maximised**.
- **A Codex agent's plan shows on the Dashboard**, and the Dashboard's plan popover scrolls.
- **A hung command shows in the stream** with Stop this call, not in the agent header.

### Sounds, flows and tools
- **Sound volume:** a master level with mute, plus a level for each alert.
- **Flow bash on Windows** runs in Git Bash, as kept processes do.
- **The Toolchain view is redesigned:** problems at the top, a card per tool with its progress, and a side panel to manage each.
- **The account pills sit in the title bar**, beside the workstation name, and the accounts popover ranks the accounts to switch to next.
- **The Dashboard's Comms column** and its arcs are back.

## Known limitations: not in this build

- The launcher.
- Moving a workspace and its agents to another machine with their identity.
- Agents on share links, visitors, attachments across a link, and direct connections without the relay.
- The new planning workflow in Genie: only its first pieces are in.
- Settings → Providers → Accounts still uses the old switch; the new one is in the account popover.
- Forgetting a Claude account leaves its sign-in folder on disk.
- Deploying from Genie.
- Genie Mail, Councils, and the mobile app.
- macOS.
