# Genie client 2026.11.28-1

## What's new
- **The Genie window is its own program.** It opens on the host the launcher gives it, or shows a list of hosts to pick from, and updating it never restarts your host.
- **Switching accounts no longer stops a busy agent.** It finishes its turn first, and its header, chat and Dashboard row say where it is moving.
- **Usage shows as soon as you switch accounts**, and each account has a **Check usage now** button.
- **An agent at its limit is held, not lost.** Messages you send meanwhile wait and are delivered once it is back; **Send all** sends them and shows each result.
- **Question windows stay open when their agent restarts.**
