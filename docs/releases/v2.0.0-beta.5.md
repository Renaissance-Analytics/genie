# Genie 2.0.0-beta.5

A rebuild from an empty repository, not a branch of the old one. The one rule: **an agent is a session, never a
terminal** — `AgentEngine` has no `'pty'` member, so "agent on a pty" cannot be written. It installs over
`0.7.0-beta.342` or `2.0.0-beta.4` in place (same appId, same install directory) through the app's own updater.

This build ships only because every v1 feature in spec §6 is in it, except GApps and agents-in-TUIs — the owner's
ruling of 2026-10-11. The §6 gap table in the envelope (`.ai/plans/genie-2-gap-table.md`) is the authoritative,
row-by-row account; this file is its summary.

## What is in it

- **Workspaces** — `.agi` envelopes; add from a folder, a git URL or a Tynn project with the plan shown before
  anything is written; folder classification, convert, import; schema stamping with backup and refusal on a newer
  revision; repo registry; per-workspace settings; hibernate (ordered, stays asleep); remove (the folder untouched,
  and the confirmation says so); ops projects governing children.
- **Agents** — register (no resources) / start (reattach, never a second session) / stop / restart graceful or
  fresh / delete (unmount vs delete, cross-system opt-in in the same prompt) / switch driver (refused when the
  persona's `tuis:` excludes it) / sidecars / personas / modes / daily budgets that park the next turn and say
  `unenforceable` / diagnose.
- **Attention** — imDone with a handoff, ForceTheQuestion (survives a restart, rejoined not duplicated), DND with a
  reply, two lists per workspace that refuse when full, thumbsUp, openFileForUser, submitFeedback, sounds, a tray
  toast naming workspace and agent.
- **AgentInbox** — durable local mail; the native transport verified at boot; reachable = permission; two-tier
  access; long-poll; read receipts; the cursor rewinds; reminders never mid-turn; attachments as byte copies with
  caps and executables refused; the human as a participant.
- **Terminals, panels, files** — real ptys (fancy-term-host 0.10.0 / fancy-pty 0.1.3); multi-attach with scrollback
  replay; hide vs close; suspend/resume; snapshots above a divider; cwd resume; a quit confirmation defaulting safe;
  manageTerminals (approval-gated); terminal, code and plugin pane kinds in four layout modes with split sizes
  remembered; the workspace file panel — tree, attribution, editing against a sha with conflicts offered in place,
  dock pin, pop-out, the agent asked to pause on a conflicted file.
- **Hosting** — `.gen` sites, background processes, shared and dedicated services, the managed toolchain with honest
  repair, Flows (an agent creates, never arms).
- **Plugins, knowledge** — signed by default; undeclared access does not exist: tool code runs outside Genie's process
  behind the guard, enabled plugins' tools are on the MCP surface, panels mount only vetted Fancy components; the
  Knowledge Graph with `[[wikilinks]]`.
- **Remote, mobile, sharing** — drive another machine (`● REMOTE — host`); the three-way settings split; PIN pairing
  with a QR that opens the phone page; the baton; the lock; share links served once; the phone: the questions, the
  agents, one agent's activity and composer, upload — no terminals, no panels, by the owner's ruling.
- **Tynn, MCP, GitHub, updates, settings** — Tynn as optional identity (gated rows annotated, never dropped);
  Genie's own MCP server on the loopback (`GENIE_MCP_URL` / `GENIE_TERMINAL_ID` in every terminal; config sync to four
  targets); the GitHub App in two steps; updates per §7 (drain roster, teardown report, the prerelease channel
  visible); two-step onboarding; settings in four groups with search.

## Known limitations — read before installing over v1

- **GApps and agents-in-TUIs are not in this build** (excluded by the ruling). A TUI runs only as a Take Over
  window, shown as an Observed row and never managed.
- **Two capabilities are in but unmeasured**, because neither test machine can run them: the external browser
  path's OS prompts (hosts file, certificate trust) and services against a real Docker. They are expected to work
  and have not been proven.
- **The Windows run of this exact build** — a real Claude Code / Codex TUI dialing the MCP loopback, the fancy-pty
  leak and console-flash acceptance, the in-place upgrade — is listed in the release request with its result; if it
  is not listed, it did not happen.
- Every plugin is unsigned today: `PUBLISHER_KEYS` is empty until a publisher publishes one, so plugins install
  only in developer mode.
- There is no macOS build in this release: macOS support is dropped for now. Windows and Linux only.

## How it was verified

Every row went red → green in a Linux test machine (WSL2 `genie-test`), never on a developer's desktop; the batch
logs live in the envelope and each pull request (#55–#80) carries its batch table and its "not measured" list. The
last suite on `main`: 1485 tests in 210 files, typecheck clean, renderer, main and preload built. `npm audit
signatures`: 363 packages with verified registry signatures, 90 with attestations.
