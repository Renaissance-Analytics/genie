## What’s new

- **Restarting an agent works again.** It replayed the flag that *creates* a session, so the relaunch died on “Session ID is already in use”. It now resumes, keeping the conversation.
- **Genie stops claiming things it never checked.** Ten places said done, ready or sent without establishing it — a prompt to a dead terminal, a process that died on launch, a dropped handoff note.
- **Agents recover when Genie updates.** The upgrade replaces the MCP server, and the channel died with it and never returned. It now reconnects, and nudges are spaced out.
- **The workstation agent knows the machine isn’t new.** It greeted you with first-time setup on every restart, and never received the upgrade notice at all.
- **Importing a Tynn project just asks where to put it** — no repo picker, no scan, no conversion, when the project already is a `.agi` envelope.
- **Kiwi and Genie agents draw their logo**, and Codex is no longer refused a restart it can perform.

## Migration

- Nothing to do. Agents whose session was captured resume on their next restart.
- If an agent still greets you as a new machine, restart it once — the marker is written on the first successful boot.
