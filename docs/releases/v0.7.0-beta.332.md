## What’s new

- **Agents can have a sidecar again.** Switching an agent to a TUI it had never run failed every time with a database constraint error; it now adds the driver and puts it in the chair.
- **The TUI you switch away from survives as a sidecar.** It keeps its own pty and conversation un-fronted, so you can flip back to the thread instead of losing it.
- **Flip an agent panel to its sidecar's screen.** The panel offers the paired `{agent}-slave` screen and back again, without starting or stopping anything.
- **Sidecars are a first-class workflow.** `runAgent` grows a `sidecar` action that names the sidecar after its driver, reuses an existing one, and delegates approval and caps.
- **Hosted sites verify the route they actually serve.** A settled browser-exposed site reconciles host Caddy from the live port and reports not-ready when only loopback answers.
