## What’s new

- **Agents stay connected when Genie updates or restarts.** There is no setting for it any more; it is how Genie works.
- **Agents’ AgentInbox channels survive updates** instead of being cut every time Genie installs one.

## Migration

- This update disconnects agents one last time. If an agent’s inbox goes quiet, run `/mcp reconnect genie-agentinbox-channel` in its terminal.
