## What’s new

- **The Genie OS agent can finish starting.** It was launched with a flag that makes Claude Code stop and ask permission — *“I am using this for local development / Exit”* — on every single launch. An agent Genie starts by itself can never answer that, so it relaunched, prompted, and went round again. The AgentInbox channel now loads as an approved channel instead, which does not prompt. Your other Claude agents stop asking as well.

## Migration

- No action is required.
- The prompt stops for each agent the next time it launches — an agent whose saved command still carries the old flag has it removed at that point.
