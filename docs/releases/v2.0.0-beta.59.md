# Genie 2.0.0-beta.59

**This release fixes the window freezing for seconds, sometimes minutes, while an agent works. Please update.**

## What's new

### The window stays responsive
- **No more long freezes while an agent sends a large reply.** Reading an agent's output used to slow down sharply as a single long line arrived, and it ran on the window's own thread, so Genie stopped responding for seconds at a time and could hang. A 60 MB line now takes well under a second instead of 26 seconds.

### Agents
- **Stop means stop.** After you stop an agent's turn, it doesn't start another one on its own. Mail that arrived during the turn waits, unread and visible, until you send the agent something.
- **Switch an agent's provider whenever you like.** The provider list in an agent's persona no longer blocks you; Genie updates it to match your choice. If a switch can't happen, for example because the provider isn't installed, the reason shows beside the control with a Retry.

### Chat
- **Jump to latest.** When you scroll up in an agent's chat, a button takes you back to the newest message and resumes following.
- **No sideways scrolling.** Long words, links and paths wrap inside the chat.
- **The slash-command menu** keeps the highlighted command in view as you use the arrow keys, and long command names wrap.

## Known limitations

- **A message already handed to a Claude agent mid-turn** can still run after you stop it. Codex agents don't have this.
- **Checking that a provider is signed in** before switching to it isn't done yet.
- **macOS** isn't supported right now, and no macOS builds are published.

## How it was verified

- **Tests and CI:** every change merged with its tests failing first, then passing. Main's CI is green on every job, including the real-window smoke on Linux and Windows and both installer builds.
- **Test machines:** the full test suite, the Flows suite and the real-window smoke ran on the Linux test machine on this exact code. The Windows test machine froze partway through its run, so on Windows this release rests on CI's full Windows unit suite and real-window smoke.
