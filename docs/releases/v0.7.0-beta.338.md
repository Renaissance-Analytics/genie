## What’s new

- **Dismissing a question keeps it.** Escape, the X and Dismiss now put a question aside in the Questions list. Only Cancel tells the agent to give up.
- **A question you can’t answer is refused before it reaches you.** An agent sending malformed options is told exactly what was wrong, instead of showing you a modal of blank buttons.
- **Genie notices an agent that has stopped moving.** `runAgent diagnose` now reports one that is bound, booted and parked on a prompt, rather than calling it healthy.
- **Messages reach an agent that restarted.** Mail queued before a restart is delivered when it rejoins, instead of being silently skipped.
