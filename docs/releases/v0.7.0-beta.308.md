## What’s new

- **Postgres now carries PostGIS as well as pgvector.** Both were offered, but only pgvector existed, so asking for `postgis` failed. One image now has both, on Postgres 14–17.
- **Ask for an extension and get it** — `vector`, `postgis`, `uuid-ossp`, `pg_trgm` and the rest install into your workspace’s own database, and come back if the engine is ever recreated.
- **Existing engines say when they are out of date**, and an operator can recreate one onto the new image — never an agent, because it restarts that engine for every workspace holding it.
- **File uploads work on a hosted PHP site.** Genie never told its PHP worker where to spool them, so every upload died before the app saw the request — nothing your code could catch or report.
- **A dead agent channel no longer swallows your mail.** A binding must now prove it is alive; a waiting poll is that proof, so mail falls back to the keyboard instead of vanishing.
- **`npm test` is honest again on Windows.** A guard read its own comment as the setting it forbids, and had been failing for every Windows developer while passing on CI.

## Migration

- Nothing to do. Postgres engines you already run keep working on their old image and will report themselves out of date; recreating one is your call, and its data volume is kept.
