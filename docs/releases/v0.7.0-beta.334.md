## What’s new

- **An empty workspace shows your agents.** Running ones appear with a live preview of their terminal; a workspace with no agents gets a short guide instead of two Add buttons.
- **The Genie window no longer scrolls.** Nothing overflows the frame, so the scrollbar down the side of the app is gone.
- **A crash or a slow start now leaves evidence.** Genie records each boot phase as it happens, so a hang names the step it stopped on, and crashes write a dump.
- **A dead terminal keeps its last words.** The output explaining why an agent exited survives the restart that `runAgent diagnose` recommends.
- **Messages to an unreachable agent stop reporting success.** A send whose transport nothing is holding now says it was queued, not received.
- **Codex agents reconnect instead of failing to authenticate.** A restart no longer replaces the token its own app-server is still using.
- **`runAgent start` says when it started a new terminal** rather than reporting a reattach it did not do.
