## What’s new

- **Terminal-host failures leave evidence.** Genie records exit codes, signals, uptime and recent spawn requests to help explain crashes that interrupt every terminal.
- **Running agents return after a restart.** Genie restores them without requiring you to open their panels; agents you deliberately stopped stay stopped.
- **IssueWatch refresh works with your signed-in session.** Refusals now explain what happened instead of appearing to do nothing.
- **Edit agents before starting them.** The agent manager opens for dormant agents too.
- **File editors follow the app theme.** Light-mode editors and file previews no longer inherit the terminal’s dark background.
