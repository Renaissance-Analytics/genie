## What’s new

- **Tailscale on Linux tells you what is wrong.** It said “Installed · offline” whether it was absent, stopped or unauthorised. Each state now names its own fix.
- **The Install button works on Linux at all** — it short-circuited on every Linux machine, believing Tailscale was already there.
- **The keychain error stops blaming packages you have.** On an unrecognised desktop Chromium never picked a store; Genie now chooses one from your live session.
- **Cloning an `.agi` envelope uses one auth path.** The parent came over HTTPS and its submodules over SSH, failing the clone with a wall of host-key errors.
- **Genie’s automation system is called Flows.** What shipped as Wishes in beta.298 is that system; a Flow’s scope is `system`, `workspace` or `gapp`.
- **A stopped dev server stays reachable.** Genie forgot a process that survived a stop, then called the next stop clean.
- **`agentUpgrade` answers for the agent asking**, not with a guide whose first step it would refuse.

## Migration

- **Linux only.** A GitHub token stored under the `basic` keychain backend cannot be read by the one Genie now picks, so it will ask you to reconnect GitHub once. Nothing was lost.
