# Genie 2.0.0-beta.40

## What's new

### Codex agents, unstuck

- **An Autonomous Codex agent no longer stops to ask.** With Autonomous on, Genie starts Codex with approvals off and
  the sandbox off (prism-acp 0.23.0's new options), so a `git fetch` or a build runs instead of parking the turn for
  hours. With Autonomous off, Codex asks as before. Autonomous now says this in its help text.
- **Approval buttons work again after the first one.** Once you had answered any approval in a window, every later
  card's buttons stayed disabled for the life of the window — a bug since beta.30. Now an answer in flight belongs to
  its own approval, ends when Genie replies, and a refused answer is said on the card ("Not answered: …") instead of
  locking it.
- **Codex agents can use Tynn's tools.** A Codex agent's call to the `tynn` MCP server was auto-declined because Genie
  only vouched for its own `genie` server. Genie now vouches for every server it wrote into the agent's config.
- **A graceful restart of a Codex agent works.** It never had: after the thread resumed, the driver asked Codex for
  its history with a value Codex 0.163 rejects, and the session died nine seconds in with "a codex app-server error"
  — so every graceful restart ended in a Restart fresh and a lost thread. prism-acp 0.23.1 asks correctly, and when
  Codex does refuse something, its own words now reach you instead of a bare error code.
- **Your message shows once.** With a Codex agent, each message you sent appeared twice: Genie recorded it as sent,
  then recorded Codex's echo of it five seconds later. The echo is recognised whenever it arrives.

### PHP: the PHP2Shell floor

- **Genie will not install or offer a PHP that is open to CVE-2026-109618 / CVE-2026-109619** (PHP2Shell, remote code
  execution in PHP core, patched 21 October). The versions Genie installs are now 8.5.12, 8.4.27, 8.3.36 and 8.2.35; a
  version under that floor is refused by name, before anything is downloaded.
- **An installed PHP under the floor is called a security update, not an "update available":** Toolchain → PHP shows
  the CVEs and the version to move to in red, beside the number, for Genie-managed versions and for the PHP on your
  PATH alike, with Update beside it.
- **The drift watcher raises the alarm.** The moment the toolchain probe (at launch and every six hours) finds a tool
  under its security floor, Genie raises the "security alert" sound and notification you chose for GitHub's — once,
  not every six hours.
- **Updating PHP names what keeps running the old one.** The php-cgi pool, `artisan serve` and the queue workers keep
  executing the old PHP until restarted; the update says so and names them.

### Agents

- **Your Active Plan survives a restart.** Genie keeps each agent's latest plan (the `plan` tool's, or the one a
  provider such as Codex reports) and shows it the moment the agent starts again — after a Genie restart, an agent
  restart, a settings change or a new conversation — until the agent reports a new one. An agent can read its plan
  back by calling `plan` with no steps, so a restarted agent knows what to pick up.
- **Switching an agent's provider starts it clean.** The new provider gets a new conversation and only a model it
  offers; the old conversation stays with the old provider, and the outcome line says so. Before, a Claude thread and a
  Claude model name were carried into Codex.
- **Delete stays inside `.agents/`.** Deleting an agent refuses any folder that does not resolve strictly inside the
  workspace's `.agents/` — a `..` or a symlink out — before the agent is stopped, so a refused delete changes nothing.
- **Ask for a handoff first.** Delete and Unmount offer to ask a running agent for a handoff (`imDone`) before it goes,
  ticked by default, waiting at most 45 seconds.

## Known limitations

- A site or process already running on a vulnerable PHP is not restarted for you; restart it after the update.
- Only PHP has a security floor so far; the probe's shape takes more tools as advisories arrive.
- macOS builds are not published in this beta.
