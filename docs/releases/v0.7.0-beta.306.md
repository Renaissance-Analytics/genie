## What’s new

- **Hosted sites stop leaking processes.** Genie recorded the shell’s process id, not the server’s, so a restart stranded each site’s server beyond its reach. One machine held 3.7 GB of them.
- **A start no longer forgets a running site**, so a site started twice can still be stopped.
- **Your agents come back.** A workspace lists the agents its `.agents` files describe, and an imported project offers the ones it brought.
- **You can switch an agent’s driver, and stop an agent.** Until now the only way to stop one was to delete it.
- **The Genie TUI installs** — from a real release download, rather than a source checkout that could never build on your machine.
- **The workspace pulse shows inbox activity** — delivered, read, replied, asked, flow run — instead of only terminal output.
- **The Flow editor is a window**, and its side panes give way to the canvas as it narrows.

## Migration

- Nothing to do. Sites started by an older Genie stay invisible to it — quit Genie and end any leftover `caddy` or `php` processes once to start clean.
