## What’s new

- **A crashlooping process is stopped instead of hammering the terminal host.** Ten failed starts in a minute and Genie gives up on it, rather than restarting it every five seconds indefinitely.
- **Terminals record why they exited.** Exit code, signal and how long the process lived, so a crash loop is visible as one instead of looking like ordinary activity.
- **Recovery after a terminal-host crash tells the truth.** It reports "degraded" when agents did not actually come back, instead of announcing success over dead terminals.
- **Codex agents start again after Genie restarts.** They were being relaunched against the previous run's app-server port and exiting immediately.
- **"Edit agent…" opens the agent manager.** It was rendering off-screen with no styling, so the menu item looked dead.
