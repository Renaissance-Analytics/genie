## What’s new

- **Restarting an agent no longer kills the agent it just started.** The panel froze until you closed it and reopened; the replacement was alive but nothing was listening to it.
- **One click reaches an agent.** Clicking an agent square starts it, opens its panel, and puts your cursor in it — it used to take three.
- **The TUI installer can actually install.** It read a table nothing ever wrote to, so every missing CLI was refused, including Genie's own TUI moments after the Toolchain page installed it.
- **Installing from the Toolchain page takes effect immediately.** Launches stayed blocked until you restarted Genie.
- **Goose works as an agent TUI.** It launches as a real session and reaches the genie MCP server, so it can call `imDone` and `ForceTheQuestion`.
- **Agents no longer capture another provider's chat session.** Eighteen of twenty-one providers watched Claude Code's transcripts, and five could resume onto one.
