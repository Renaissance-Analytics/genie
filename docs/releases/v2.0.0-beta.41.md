# Genie 2.0.0-beta.41

## What's new

### Creating an agent asks you first

- **"+ Add agent" opens a New agent form** instead of creating `agent-<time>` on Claude with nothing in it. It asks for
  a **name** (and shows the folder it becomes under `.agents/`), a **purpose** (required — it goes into the agent's
  AGENT.md) and the provider it **starts on** (Claude or Codex). Model, mode and permissions are in the agent's
  Settings, which open as soon as it is created.
- **The name is checked before anything is written:** a reserved name (general, genie, tynn — unless your linked Tynn
  project grants one), a name the workspace already has, or one that cannot be a folder is refused on the form, in
  words.
- **Every new agent gets its `AGENT.md`**, written at `.agents/<name>/AGENT.md` — never over one that is already
  there. That is what makes **Unmount** safe: an agent with nothing on disk used to be lost the moment it was unmounted;
  now it can always be reattached from the workspace's Agents list.

### When a run fails, you can read why

- **A failed run leaves its reason in the agent's history:** what failed, how the provider exited, and the last lines
  it wrote to its error output. Before, they lived only in memory, and a restart erased them — which is how a Codex
  agent's graceful-restart failure stayed a mystery for a day.

### Steadier agents

- **A malformed rate-limit message can no longer crash a Claude agent** (prism-acp 0.23.2): a reset time past what
  JavaScript can represent used to end the agent's process; it is now ignored like any other malformed field.

### Small things

- **"thinking" underlines when you hover it** in the chat, so it reads as something you can open.

## Known limitations

- Several screens still recompute over an agent's whole history on each update; with very long histories that is
  still noticeable.
- macOS builds are not published in this beta.
