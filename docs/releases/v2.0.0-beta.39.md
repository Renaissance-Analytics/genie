# Genie 2.0.0-beta.39

## What's new

### Your agents can reach Genie again

- **Claude agents have Genie's tools back.** Since beta.35, every Claude agent started without Genie's tools
  (`agentinbox`, `imDone`, `plan` and the rest): three new tools were sent without a title, and Claude Code refused
  Genie's whole tool list because of them. They have titles now, and a test checks every tool Genie offers so it can't
  happen again. This is also why Codex agents sat idle: the agents that hand them work couldn't send it.

### Restarting an agent brings it back

- **Restart starts the agent again.** A restart now waits for the old session to finish stopping before it starts the
  new one. Before, a Claude agent was still stopping when the new start came, the start was refused, and the agent
  stayed stopped ("not running" on your next message).
- **Restart fresh never loses your conversation for nothing.** The old conversation is set aside only once the new
  session has started. If the start is refused, your conversation stays and you see why.
- The same wait now applies when a settings change restarts an agent, when you sign in again, to "Restart with this",
  and to switching an agent's provider.

### No more freezes while agents work

- **The window no longer freezes each time an agent does something.** Every update from an agent you were watching
  copied that agent's whole history into the window, once for the Agent view and again for the chat. Now only what
  changed is passed, so an update costs the same whether an agent has a short history or a very long one.

### Agent settings in tabs

- **Settings is split into General, Permissions, IssueWatch, Persona and Skills.** Provider and model sit side by side
  at the top of General, with Unmount and Delete in their own area at the bottom. Each permission is one row with one
  line of help. The 13 IssueWatch events are in three columns. Context, cost and turns are in a strip above every tab,
  and a setting's result appears next to it.

### Picking a folder

- **Up, your drives, and New folder.** When you choose where a workspace lives, you can go up a folder, jump to any
  drive (or `/`), click a drive in the path, or type a path, and create a new folder right there. It is created on the
  machine that holds the workspace.

### Release notes

- **The update window re-reads the notes** when it opens, so an update found before its notes were ready no longer
  shows "No release notes were published".

## Known limitations

- Several screens still recompute over an agent's whole history on each update; with very long histories that is
  still noticeable, and it is being worked on.
- A window connected to another machine still receives an agent's whole history on each update.
- Codex: a few things about Codex agents are still being looked into.
- macOS builds are not published in this beta.
