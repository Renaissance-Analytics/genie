## What’s new

- **Genie’s PHP has the extensions your app needs.** The build ships 37 and only 14 were on, so an app reaching for `mysqli`, `pgsql`, `soap` or `ldap` failed deep inside a request. Now 32.
- **`redis` is kept when you add it.** It is absent from the official Windows build, so drop the extension beside your PHP and Genie stops erasing it on the next launch.
- **A new project decides what it is before its stack.** A skill asks whether it is even a code project, whether a spec exists, and where it will run — then recommends TypeScript or Python.
- **Two build-toolchain advisories closed** — an override was pinning one to the very version the advisory names.

## Migration

- Nothing to do. Every Genie-managed `php.ini` is rewritten on the next launch, so an existing PHP install gains the extensions without reinstalling.
- Four stay off on purpose: `opcache` kills `php-cgi` on Windows, `snmp` and `pdo_firebird` warn on every run, and two are PHP’s own test extensions.
