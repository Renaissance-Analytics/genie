## What’s new

- **Reset Workstation no longer bricks Genie.** It deleted folders holding running executables, which Windows refuses — and the failed reset re-ran on every boot, so reinstalling did not help.
- **AgentInbox stops typing at your agents.** Mail for a Claude agent was written into its terminal, arriving as if you had typed it. It now travels over the Claude Channel.
- **Agents can no longer see other workspaces.** Service inventory named every workspace on the machine to any agent. It now says only whether an engine is shared, never by whom.
- **Genie starts on Linux again.** The AppImage needed FUSE 2, which Arch-based systems like Omarchy no longer ship, so it died before starting. Verified on a real Omarchy 4.0.2 machine.
- **Providers settings covers every TUI**, so Kiwi and Genie are configurable at last, and `--genie-debug` writes a startup log you can send us.

## Migration

- **If a reset already bricked your install**, delete `%APPDATA%\genie\.reset-workstation` and start Genie. Your workspaces and toolchain are untouched.
- Nothing else to do. Existing workspaces gain their workspace agent automatically.
