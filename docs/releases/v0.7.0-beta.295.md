## What’s new

- **Fixes agent panels, which beta.294 broke.** Every agent in every workspace failed to open with “Cannot read properties of undefined (reading 'slice')”. Nothing else was wrong with them.
- **The cause was half a rename.** beta.294 renamed an agent’s driver to `tui` where it is sent, and left the name `provider` where it is read, so the panel got nothing and threw.

## Migration

- No action is required, and nothing was lost — your agents were always there, only the panel could not draw them.
- Do NOT roll back to beta.293. beta.294’s database changes have already applied, and beta.293 does not understand them.
