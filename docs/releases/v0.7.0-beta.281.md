## What’s new

- Genie now bundles a native WebSocket service, so workspace broadcasting no longer needs a Docker image.
- WebSocket apps remain isolated per workspace and work from both Host-native and containerized sites.
- The service manager remains available without Docker for Host-native services.
- What’s New popovers are limited to four highlights and one migration note.

## Migration

- No action is required; existing Reverb-compatible workspace settings continue to work.
