# Genie 2.0.0-beta.20

## What's new

- **Doctor mode.** Start menu → *Genie (doctor mode)*, or `Genie.exe --doctor`, opens Genie with only **genie**, the
  workstation agent. Doctor mode never opens Genie's configuration or database. Genie runs in a window of its own, with
  the install's facts, genie's Stream and its chat. genie diagnoses and repairs the install with its
  `genie-diagnostics` skill, and backs up any file before changing it. Claude Code can connect to a doctor channel to
  help; the doctor window shows the line to paste.
- **genie can be started, and lives on the workstation.** The Agent view has **Start** for any agent that is not
  running. A message to a stopped agent starts it and sends the message. genie runs in `~/.genie/osa`, with
  instructions built into Genie and the diagnostics skill always on.
- **The model, shown and chosen.** Each agent's rail shows the model the provider says it is using. You pick one
  (Claude: default, sonnet, opus or haiku; other providers: a name), and the change applies at the next start.
- **Claude agents can ask before shell commands.** A third tool setting, next to *all tools* and *edits only*: each
  shell command (Bash, and PowerShell on Windows) waits for your approval in the chat, like Codex's approvals.
  Anything but an explicit allow blocks it.
- **The context bar tells the truth.** Claude's context now counts the cached conversation it holds. It used to show
  numbers like "675 / 1000k".
- **Chat.**
  - Always present as tabs: a strip on every surface, or pinned.
  - Your own messages are in the thread.
  - Replies are rendered properly, not as raw Markdown.
  - An agent's mail with other agents shows as a line in its thread.
  - The composer names who you're writing to.
- **The Stream is what the agent is doing:** thoughts (click to expand) and tool calls, one row per call. Replies are
  in the chat.
- **Finished agents no longer read "Working".** A turn's end now updates every screen at once.
- **The header.**
  - The update notice is in the title bar on every page, no longer on the Deck.
  - The window's minimize, maximize and close buttons no longer cover the header, and they follow the light or dark
    theme.
- **Updates: stable and dev channels** (Settings → General). *dev* (the default) offers every build; *stable* offers
  full releases only.
- **Workspaces keep their agents in step.**
  - Genie 2 upgrades a Genie 1 workspace's agent files: the MCP entries, the protocol, the `AGENTS.md`/`CLAUDE.md`
    routers, `RULES.md` repair and the skills.
  - It gitignores the files that carry its MCP token.
  - Settings shows, per workspace, whether those files are current, upgraded or failed.
- **Genie's MCP comes with every agent session,** keeps its port across launches, and Settings lists its tools.
- **Fixes.**
  - Workspace names everywhere, never their ids.
  - Settings' tabs switch.
  - The file panel's open file and filter are in the URL.
  - The Dashboard has its comms cell, the collaborator reveal and the row tray.
  - The Agent view shows the headroom, turn and session cost, and in/out tokens.

## Migration

Installs over any earlier Genie in place, through the app's updater or the installer.

- Genie 1 workspaces, agents (claude and codex) and settings are imported on first boot, as before.
- A workspace's Genie 1 agent files are upgraded on first boot, each rewritten file backed up first under
  `.agents/_genie/backups/`.
- Upgrades no longer ask agents for a handoff: installing ends the sessions.
- A stored update channel of `beta` reads as `dev`.

## Known limitations

- **GApps and agents-in-TUIs are not in this build** (the owner's ruling). A TUI runs only as a Take Over window.
- **Claude's reasoning text is not shown.** Measured: Claude Code sends thinking blocks with the text withheld in this
  mode, so the Stream says "Reasoning not sent by the provider".
- **Attachments in the composer are not sent yet.** The driver takes text only (prism-acp-ts#4).
- **Still not on the wire, so not drawn:**
  - which lines an agent is writing (the presence pill and line tags);
  - commit and answer chips on turn cards;
  - the plan step that started a turn;
  - `Ln, Col` (fancy-code#6).
- **Unmeasured:** the external-browser path's OS prompts, and services against a real Docker.
- Windows and Linux only; no macOS build.

## How it was verified

- **Every change went red → green** in a Linux test machine (WSL2), never on a developer's desktop. Each pull request
  carries its evidence.
- **Doctor mode was run six times on a real workstation with its owner's signed-in Claude**:
  - the channel announced only on first use;
  - read-only diagnostics of a real `~/.genie`;
  - the turn-end fix measured at 5 s, against 600 s before;
  - direct answers;
  - the model and the true context reported.
- **prism-acp 0.8.0, 0.9.0 and 0.10.0** (the model, true usage, Claude's permission prompts) were each measured live on
  real Claude and Codex logins before release.
- **The Windows VM** builds the installer, installs it, and drives the installed app over CDP. That covers the header
  checks, plus both Start-menu shortcuts after install and both gone after uninstall.
