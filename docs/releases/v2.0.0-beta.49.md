# Genie 2.0.0-beta.49

## What's new

### Fixed: the whole window scrolled

In beta.48, a long chat could make the whole window scroll, so the sidebar, the main area and the chat slid up and left blank white below (#1290).
- **Locked:** the window itself can no longer scroll. Only the panes inside it do, as in Genie 1.
- **Contained:** the chat's copy-button status messages now stay inside the chat.
- **No scroll on focus:** moving the cursor into the chat box (Ctrl+J) or the find box no longer scrolls anything.

## Known limitations

- macOS is not supported right now, and no macOS builds are published.
- Connecting to your other machines (workstations) is being reworked in the next release.
