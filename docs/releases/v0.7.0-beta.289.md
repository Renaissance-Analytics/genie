## What’s new

- **The Genie TUI launches.** It was looking for a `genie-tui` binary that does not exist. Correcting that in beta.288 fixed nothing on a machine that had already run Genie, because the dead name was cached in two places that outrank it — this release clears them.
- **Right-click a paused agent.** Start it, or make it your workspace’s default. Agents that were not running had no menu at all.
- **Right-click a leftover.** The square left behind after an agent is deleted now offers to remove itself, instead of answering with nothing.
- **Hovering the agent avatars gives you the agent.** Status, stats, and the same controls you get with the sidebar expanded — it opens to the right of the avatars.
- **Switch an agent’s TUI from its panel.** The control was built and never appeared, because nothing told it which agent it was on.
- **Set a workspace icon and agent avatars.** Any emoji; clear it to go back to the workspace’s initials or the TUI’s own logo.
- **Ask Issue Watch to re-read GitHub now**, from a button in its header. Tynn allows one refresh per workspace every three minutes, shared with your agents.
- **“Tynn isn’t tracking this workspace” now tells you what to do about it** — and gives you the control for it, instead of asking you to go and check things Genie already knew.
- **Menus stop calling agents “terminals”.** Deleting an agent said “Delete terminal”, which reads as closing a shell.
- **The site and process controls are two stacked boxes** on the right edge of the workspace row, and the GApp launcher sits beside the agent avatars.
- **The “install the App” and “add a permission” links work again.** The GitHub App was renamed, so every one of them was a 404 — including the ones you would follow to fix a permission problem.
- **Docs cover Genie Apps.** GApps, GApp Development Workspaces, the manifest, permissions, and the check/preview tools had no page at all.

## Migration

- No action is required. Genie repairs the stale Genie TUI command on first launch.
- If Issue Watch shows `?` on every workspace, your GitHub session has expired — use **Reconnect GitHub** in the Issue Watch panel.
