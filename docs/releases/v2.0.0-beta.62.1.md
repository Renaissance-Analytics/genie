# Genie 2.0.0-beta.62.1


**A security housekeeping release on beta.62: two code-scanning alerts closed. Nothing you use changes.**


## What's new

- **Two code-scanning alerts are closed** (#107 and #108). Both were in Genie's own test and measurement code, not in what Genie runs: a test helper now strips markup completely, and a measurement script checks an event handler before calling it.

## Known limitations

- The same as beta.62: a terminal can stop redrawing until you scroll or resize it; raw "unhandled promise rejection" items can still appear in the Deck while Genie restarts; very large setups still peak near 0.9 GB.

## Not in this build

- Everything planned for beta.63 (plain-words errors in the Deck, several accounts per provider, and the rest).
- macOS.
