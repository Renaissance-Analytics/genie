## What’s new

- **PHP sites stay up.** Genie’s PHP worker used to exit on its own after 500 requests, so a `.gen` site started answering 502 a few minutes into testing. It now keeps running, and a worker that does stop is brought back instead of leaving the site down.
- **New setting: “Keep agents connected through Genie updates”** (off by default). When on, agents reach Genie through a small background service that stays running while Genie updates or restarts, so their connection is not dropped.

## Migration

- PHP sites that are running when this update relaunches Genie restart once, so they pick up the fix.
- The new setting is off; nothing changes unless you turn it on.
