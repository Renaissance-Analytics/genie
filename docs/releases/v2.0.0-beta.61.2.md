# Genie 2.0.0-beta.61.2


**A hotfix for beta.61.1: your Pilot is a Pilot again, and interrupting an agent so it reads your messages works. Please update.**


## What's new

- **Your Pilot is shown as a Pilot again.** Since beta.61, Genie could fail to read this workstation's role from Tynn and fall back to Drone. It now reads it correctly, so the host picker and Pilot controls are back.
- **Interrupting an agent delivers your queued messages.** Pressing Interrupt while an agent waits on a long Genie tool call no longer stops it and leaves your messages "Not delivered".
- **A security fix** in how Genie serves an app's files.
- **Test files hold only made-up values** (no real names, emails or token-shaped strings).

## Known limitations

- **A terminal can stop drawing** until you scroll or resize it: the text reaches the terminal but the pane isn't redrawn. Close and reopen the terminal, or resize it. The fix is being worked on.
- **The hang check can report an agent as stuck** when the whole machine stalls for several seconds. The fix ships in beta.62.
- **A broken Claude or Codex install is detected and named, not yet repaired from Genie.** Reinstall it with the vendor's installer for now.

## Not in this build

- The chat staying on the agent you selected when you change pages (62).
- Settings → Remote access showing only this machine's settings (62).
- Image thumbnails on hover for sent attachments (62).
- Repairing a broken Claude/Codex CLI from Genie (62).
- The send-key hint inside the composer, and the send flicker fix (62).
- The question cards layout (62).
- Per-agent skills and MCP switches beyond what 61.1 has (62).
- Several accounts per provider (63), Genie Mail (64), Compliance (65).
