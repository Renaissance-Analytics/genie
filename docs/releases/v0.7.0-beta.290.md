## What’s new

- **Messages reach your agents without going through your keyboard.** The AgentInbox channel had never worked — the file Genie generates for it was missing a line and would not even parse, so the process died on launch every time. Everything fell back to typing a nudge into the terminal, which had to wait for you to finish what you were typing. The channel now connects, and mail arrives out of band.
- **The Genie OS agent has its tools.** Its workspace was never wired — on any machine, on any launch — so the operator that manages workspaces, onboarding and upgrades booted with none of the tools its own instructions named, and asked you to approve a channel it could not then load. It is wired before its agent starts.
- **Clicking a paused agent starts that agent.** It used to spawn a second one alongside it and leave the original sitting idle, so the same agent appeared twice in the rail.
- **Agents can be deleted.** Right-click one and choose **Unmount from Genie** — which shuts its TUIs down and keeps every file under `.agents/` so you can add it back untouched — or **Delete for real**, which also removes those files. The prompt says plainly which one keeps what.
- **A TUI that is not installed says so.** Genie checks for the binary when it starts, and refuses to open a terminal that would only print `command not found`.
- **A deferred answer tells you why it was deferred.** Every late answer claimed you had been in Do Not Disturb, even when you were simply away, or right there and answering normally.
- **Genie stops reporting healthy workspaces as broken.** A `CLAUDE.md` that differs from `AGENTS.md` only by its per-harness import is the supported shape — Genie writes it that way itself — and is no longer called divergent. When the Genie section really is damaged, Genie now names the file that holds it instead of always blaming `AGENTS.md`.
- **Agents are told which branch a repo is on**, and how far it has drifted from its remote, when they start. An agent could otherwise spend an afternoon reasoning about code you are not running.
- **The “I’m done” hook is set up for you.** Every Claude agent had to wire it by hand before doing any work, from instructions that described a hook shape Claude Code does not actually run — so agents that followed them exactly ended up with a hook that never fired.
- **Right-click menus are readable.** They were transparent, with whatever sat behind them showing through.
- **Dialogs have their titles back.** The New Agent and Send Feedback dialogs rendered with no header at all, which clipped the first field’s label against the top edge.

## Under the hood

- Every Fancy package moves to its latest release, including a major version of the UI kit.

## Migration

- No action is required.
- Agents running from before this release should be restarted to pick up the working AgentInbox channel.
