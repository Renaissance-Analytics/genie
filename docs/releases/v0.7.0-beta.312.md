## What’s new

- **Your services come back after a reboot.** If Docker started slower than Genie, new terminals got no database at all — silently, with no retry. Genie now retakes that pass.
- **No more “start Docker Desktop” while Docker is running.** That advice stops every container on the machine, and it was being given when starting the service would have worked.
- **A stale failure is now retired.** A service that failed while Docker was still booting stayed marked failed forever. The claim is withdrawn once the machine it described is gone.
- **Empty is no longer reported as success.** When a workspace that enabled services gets nothing, agents are told why instead of receiving a green result with an empty payload.

## Migration

- Nothing to do. If a reboot left your terminals without services, opening the workspace recovers them.
