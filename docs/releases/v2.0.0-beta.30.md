# Genie 2.0.0-beta.30

## What's new

### Faster, and back to Genie 1's file browser

- **The file browser no longer slows your computer down.** It used to read the whole workspace again for every file
  that changed, so an agent building or running tests could bog everything down. It now lists the way Genie 1 did:
  quickly, within a sensible limit, without `vendor`, `dist`, `build` and other generated folders, and with live
  updates gathered into one refresh at a time. An open file reloads only when that file changed.
- **When an agent opens a file for you, it opens in Genie,** in that workspace's file panel, not in whatever app your
  computer uses for that kind of file.

### Getting around

- **Agents open inside their workspace,** as they did in Genie 1. An agent's page sits under its workspace's own tabs:
  Agents, the agents you've opened (each with its state, and a × to close it), your tabs and Settings, so another
  agent, the workspace or its Settings is one click away.
- **On an agent's page you know where you are.** Its workspace stays highlighted in the sidebar, and the workspace
  name at the top of the agent is a link back to it.

### Rate limits

- **Hitting a rate limit pauses your agents instead of breaking them.** Every agent on that account waits, its
  prompts are kept, and it carries on by itself shortly after the limit resets.
- **You can see the countdown everywhere:** on the agent, on the Dashboard and in the chat, with **Resume now** if
  you want to try sooner.

### Agents

- **Stopping an agent stops all of it.** Nothing it started keeps running in the background, and when Genie starts,
  anything left over from before is ended first, so no agent is ever driven twice.
- **Mail wakes an agent.** A message to an agent that isn't running starts it.
- **Agents can work on their own.** Turn on autonomy for an agent and its services, processes, sites and terminals
  run without asking you each time. Everything it does is recorded.
- **Agent settings are a Settings tab** on the agent's screen, out of the way of the conversation.

### The Command Window, prompts and keys

- **Ctrl+K (⌘K) opens the Command Window:** search and jump to actions, workspaces and agents. Type `p>`, `a>`, `w>`
  or `@>` to narrow it. Enter opens the first match.
- **Saved prompts with their own hotkeys.** Make prompts in Settings → Agents, give each a key, and send one to the
  agent in front of you with a keypress or from the Command Window. Your Genie 1 prompts come across.
- **F5 nudges an agent to ask properly:** it tells the agent to use ForceTheQuestion. Both F5 and Ctrl+K can be
  changed in Settings → General → Keyboard shortcuts, and your Genie 1 keys come across.
- **Ctrl+W no longer hides Genie,** and **Ctrl+, opens Settings.** Genie has a proper menu again: Edit, View, Window
  and Help with your version.
- **Esc in a question window means Later:** the question waits for you with what you typed, and the agent is never
  told you dismissed it.

### Sounds

- **Every kind of thing an agent does can have its own sound,** grouped as Needs you, Its turn, Its work and
  Messages: from asking you something and hitting a rate limit, to finishing a reply, editing a file or running a
  command. The quiet everyday ones start silent.
- **Choose the sound for each,** with Preview: the Default chime, 3 Toot Pipe, Ding Dong Doink, Sparkle,
  Triumphant, Wind Down, **your own file**, or None.
- **Your Genie 1 sound settings come across,** including your own sound files.

### The workspace and the window

- **Design your own workspace tabs.** Between Agents and Settings, add tabs with a grid of panels: terminals, files,
  your sites and more.
- **The sidebar has Genie 1's tools again:** collapse it to icons, System, hibernated workspaces, add, and a filter.
- **The pinned chat is wider,** and you can drag it wider still. It remembers.
- **Approval requests stack** in the corner of whatever screen you're on: scroll or use the arrow keys to go through
  them and answer each in place.

### Fixes

- A slow Docker change is waited for and checked, not reported as a failure.
- A build-time security advisory (Dependabot #75) is resolved.

## Known limitations

- **The sidebar doesn't list a workspace's agents under it yet.** That comes next.
- **A file an agent opens for you opens at the top,** not yet at the line the agent named.
- **A window driving another computer doesn't play the new per-action sounds yet.** The computer's own window does.
- **More sound choices are coming:** a set of new synthesized sounds, and a public-domain sound library to choose from.
- **On some Linux desktops the menu's own shortcuts don't fire.** Genie's keys (Ctrl+K, Ctrl+, F5 and your prompts'
  keys) work everywhere.
- **The window can still freeze briefly when an agent starts or stops.** Genie still scans running processes at those
  moments and waits for the scan. The fix is planned.
- **Remote and sharing are not yet at Genie 1's level.** That covers Tynn workstation registration and tunnels,
  workspace and workstation sharing, and finding your Tailscale machines.
- **Adding a workspace offers a folder only for now.** Genie 1's other ways (new, from Git, from Tynn) are planned.
- **PHP sites run on php-cgi.** FrankenPHP as the default PHP server and Laravel Octane are planned.
- **Some Genie 1 features are not in Genie 2 yet,** including the Feedback hotkey and window, IssueWatch and the
  Knowledge Graph editor.
- **An agent that is already running keeps the service variables it started with.** It gets new ones from
  `services exec` or after a restart.

## How it was verified

- **The full unit suite passed three times,** with typecheck and the renderer build, in a Linux test machine. Every
  change was written test-first, and each test was watched failing before the fix went in.
- **Every change passed all eight checks before it merged,** including a real Genie window on Linux and on Windows that
  opens the Command Window, makes a saved prompt and gives it a hotkey, and presses Ctrl+, and Ctrl+W.
- **The file browser:** a burst of 40 file changes now arrives as at most 3 updates carrying all 40 files, where each
  change used to re-read the whole workspace.
- **Windows:** checked in the Windows test VM before tagging.
