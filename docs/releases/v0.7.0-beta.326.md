## What’s new

- **Serve a PHP site with FrankenPHP:** one process with no separate PHP worker. Pick it in the site’s Edit form; Genie downloads it on first use.
- **Run Laravel Octane sites** on FrankenPHP, RoadRunner or Swoole.
- **A PHP site runs the PHP its composer.json asks for**, instead of whatever the machine default happens to be.
- **Agents waiting on Genie always get an answer** when Genie is not running, instead of hanging.

## Migration

- Nothing to do. PHP sites stay on the same serving mode, and each site keeps the PHP it runs on today.
