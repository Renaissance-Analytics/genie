# Genie 2.0.0-beta.66.2

**Switching accounts now shows the new account's usage at once and tells you where each agent really is. An agent that hits its limit waits and moves to an account with room, and your messages go with it. Question windows stay open when their agent restarts.**

## What's new

### Accounts and limits
- **A switched-to account's usage shows at once.** Genie reads the new account's limits as soon as you switch, the first time an account is used, and while the Accounts panel is open. No more "Usage unknown" that never updates.
- **Check usage now.** Every account in the Accounts panel has a button that reads its usage on the spot and says so if the read fails.
- **Every agent says which account it is on.** A busy agent finishes its turn before it moves, and its header, chat and Dashboard row say "On <old> · moves to <new> at next idle". **Restart on <new> now** moves it straight away.
- **An agent that can't move says so.** If its conversation can't be opened on the new account, it reads "Stays on <old>" and says why. Restarting it there asks you first, because it starts a new conversation.
- **The limit line names its account.** The stream's limit line says which account the figure belongs to, for example "67% of 7d window left on Aux".
- **An agent that hits its limit waits for room.** When Claude refuses an agent because its account is spent, the agent is held and moves to an account with room. A hold that resumes on another day shows the day, such as "resumes Thu, Dec 3, 7:15 PM".
- **Messages sent during a hold or a move are kept.** They show "Waiting · sent when <agent> is back" and are delivered once the agent is up again, instead of showing "Not delivered".
- **Send all sends.** Send all delivers every waiting message and shows the result for each one.
- **Choose what happens when the active account runs out.** A new setting in Settings → Providers, "When the active account runs out", offers **Ask me** (the default) or **Switch to the account with the most room**.

### Questions
- **A question window no longer closes when its agent restarts.** Restarts, account moves and upgrades leave the question open, and your answer still reaches the agent. A question is marked stale only when its agent is removed, and even then the window keeps your draft and offers **Answer anyway**.

## Known limitations
- Checking an account's usage sends one tiny message from that account, so it counts for a little of that account's usage. On its own, Genie reads each account at most once every 15 minutes.
- A slow but normal "Shut down everything" can still be recorded as an unclean end and start Genie in safe mode next time. Leave safe mode gets you out with one click; the cause is fixed in a later release.
