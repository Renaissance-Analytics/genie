## What’s new

- **Starting an agent works again.** In beta.290 an agent you created from the New Agent form would start — a terminal really did open — but Genie could not see that it had, so no agent box appeared and it stayed looking dormant. A fix in beta.290 made the agent’s runtime record the source of truth for “which terminal is this agent in”, and the code that writes it could only update a record that already existed. An agent that had never run has none, so the first start wrote nothing. It is created now.
- **A question you answer can no longer be thrown away.** If an agent asked you something and had nowhere for the reply to be delivered — the workstation operator, or an agent started by hand outside Genie — the question was still accepted, you still answered it, and the answer was discarded. From your side it looked like the agent ignored you. Such an agent is now refused when it asks, and told to ask you directly instead.

## Migration

- No action is required.
- If an agent from beta.290 still shows as stopped while its terminal is open, start it once more — the missing record is created on the next bind.
