# Genie 2.0.0-beta.44

## What's new

### Genie's own languages

**Settings → Toolchain** now installs and manages versions of Go, Node, Python, PHP, .NET, Rust, Ruby and Java, each
into Genie's own toolchain folder. Every download comes from the language's official publisher (Eclipse Temurin for
Java) and is checked against the checksum it publishes before anything is written. An install counts only when the new
version runs and reports itself; a failed install leaves nothing behind.

- **Go**: go.dev's builds, on Windows and Linux.
- **Node**: nodejs.org's builds, now on Linux too.
- **Python**: python.org's own package on Windows, with `python` and `pip` as commands. Built from python.org's source on
  Linux.
- **PHP**: built from php.net's source on Linux, with every extension Genie's PHP enables compiled in (Windows already
  had php.net's builds).
- **.NET**: Microsoft's SDK archives, on Windows and Linux.
- **Rust**: through rustup, on Linux.
- **Ruby**: built from ruby-lang.org's source on Linux; RubyInstaller on Windows.
- **Java**: Eclipse Temurin JDKs for the LTS lines 25, 21 and 17, on Windows and Linux.

On Linux, a source build first checks for the compiler and libraries it needs. If any are missing, it names the
packages to install before downloading anything.

**A default per language.** Make any installed version the default and `node`, `python`, `pip`, `go`, `cargo`, `ruby`,
`gem`, `java`, `dotnet` and the rest run it in Genie's terminals, processes and agents. Switching repoints one link, so
nothing has to restart. A .NET default also sets `DOTNET_ROOT`, and a Java default sets `JAVA_HOME`.

**In every terminal, if you want.** A new "Your terminals" card puts Genie's defaults on your machine's own PATH. It
asks first, shows exactly what changes, and has Undo, which restores your PATH exactly.

### Agents

- Changing a Claude agent's tool setting (all tools / ask before shell commands / edits only) now applies from its
  next shell command. Nothing restarts, and a command already waiting on you is answered by the new setting. Who can
  reach an agent was already applied at once, and is now covered by a test.

### Chat and Stream

- Following Live keeps only the last 500 lines in view, with earlier history paging in, and each update reads only
  what is new. Very long conversations no longer slow the window down.

### Rate limits

- The time a rate-limited agent resumes is shown as 2:31 PM, not 14:31. Hover it for the full date and time. The
  plan-window reset reads the same way.

### Fixes and security

- Hibernated workspaces no longer appear on the Dashboard.
- Updated the provider bridge to prism-acp 0.25.2, which locks down the Windows credential directory and redacts
  API-key-mode Claude output.
- Patched undici and fast-uri. Hardened how Genie checks process arguments, test-VM HTTPS probes and certificate
  signatures. Front-door work that fails is now reported instead of hanging.

## Known limitations

- macOS is not supported right now, and no macOS builds are published.
- Rust is not offered on Windows yet.
- On Windows, Ruby gems with native extensions need RubyInstaller's DevKit (MSYS2), which Genie does not install.
- "Edits only" now means shell commands are refused and everything else runs. It has not been checked against a real
  Claude session.
- Per-agent Tynn credentials are still not switched on.

## Verification

- Every language was installed for real on the test VMs, with the publisher's real downloads:
  - **Windows:** Python 16 of 16 checks, .NET 13 of 13, Java 12 of 12, Ruby 14 of 14.
  - **Linux:** Go 7 of 7, Node 8 of 8, Python 16 of 16, PHP 14 of 14, .NET 11 of 11, Rust 12 of 12, Ruby 12 of 12,
    Java 10 of 10.
  - Each run refused a tampered checksum and left nothing behind, made the version the default, used it by name, and
    removed it.
- On Linux, every source build compiled from the publisher's tarball.
- The PATH card was proven on both systems: applied, then undone exactly.
- The Omarchy (Linux) test VM ran the full suite and typecheck on each change. Linux CI and the Windows real-window
  smoke test passed on each merged change.
- Windows unit tests failed on main from #1182 until #1193, because of two test fixtures that built paths with
  backslashes. Genie itself was not affected. After the fix, the full Windows suite passed on the Windows test VM (786
  files) and on main's CI.
