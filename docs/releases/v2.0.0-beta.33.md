# Genie 2.0.0-beta.33

## What's new

### Your agents come back

- **Agents that were running come back after Genie restarts or updates,** every time. There's no setting for it
  any more. An agent cut off mid-turn is told to continue; an agent you stopped stays stopped.
- **Every agent of a workspace is a tab,** running or not, so you can always get to an agent. (In beta.32 only
  agents you had opened had tabs.)

### The chat

- **An agent's reply shows as it writes it,** not only when its turn ends.
- **A message you send while the agent is in the middle of a step says it's waiting,** and what it's waiting
  behind. **Interrupt and send** stops that step and delivers your message now.
- **A message that couldn't be delivered sits where you wrote it.** Once the agent is running it offers
  **Send now**, and any of them can be **discarded**.
- **Your answers to an agent's questions, and AgentInbox mail, show in the chat with what they say,** and open in
  the inbox when you click them.

### AgentInbox

- **AgentInbox opens from the header,** with the unread count on its icon, instead of being a page in the menu.
  Threads, search across every message, filters, history, attachment downloads, agent-to-agent threads (read-only),
  Mark all read and Delete thread.

### Approvals

- **Every approval takes a note,** in the chat, on the agent's page, in the Deck and in the popups. The agent gets
  it with your answer: "You rejected …: <your note>".

### The Active Plan

- **Agents can now fill their Active Plan column.** Genie gives every agent a `plan` tool, so the column shows the
  agent's steps and which one it's on, for any provider.

### Files

- **Markdown opens rendered, and you edit it there,** with a drawer for its front matter. Word documents,
  spreadsheets (.xlsx, .csv) and presentations (.pptx) open in their own editors too: Genie 1's official Document,
  Spreadsheet and Presentation plugins are back, listed first in Settings → Plugins, and each can be turned off.
- **Each open file keeps its own unsaved changes** when you switch tabs.

### GitHub

- **Your GitHub sign-in from Genie 1 carries over;** you don't sign in again. Where it can't (a different Windows
  user, say), **Sign in with GitHub** shows a code and opens GitHub in your browser.
- **Settings → GitHub shows what GitHub says:** the account signed in, where the Genie app is installed, the
  repositories it can reach and the permissions it has. GitHub features follow those permissions. (It used to be a
  checklist you ticked by hand.)
- **Cloning a private repository uses that sign-in.** The token is never written into the repository.

## Known limitations

- **Genie can get slow with a very long agent conversation:** text and questions can take seconds to appear. The
  fix is the next release's first item.
- **On Windows, stopping or restarting an agent can leave its old Claude process running** until Genie restarts.
  The fix is tested and comes in the next release.
- **Updating Genie still restarts everything,** including terminals, processes and sites. Updates that leave them
  running when only the window changed come in a later release.
- **Each PHP site still runs in a terminal of its own, behind its own Caddy.** One server for every site
  (FrankenPHP, PHP 8.5) is in progress.
- **Codex agents don't have Interrupt and send yet;** a message sent mid-turn waits until the turn ends.
- **Installing and choosing versions of Node, Python, Go, Ruby, Java, .NET and Rust** from the Toolchain is still to
  come.
- **Signing in to an agent provider is done in the provider's own window.**
- **A window driving another computer doesn't play the per-action sounds yet.**
- **On some Linux desktops the menu's own shortcuts don't fire.** Genie's keys work everywhere.
- **.odp presentations and .ods spreadsheets** open read-only or not at all until their formats are supported.
- **The Knowledge Graph editor from Genie 1 is not in Genie 2 yet.**

## How it was verified

- **Every change was written test-first,** its tests watched failing before the fix went in, and it passed all
  eight checks before it merged, including a real Genie window on Linux and on Windows.
- **Your GitHub sign-in carrying over was measured on the real machine** it was written for: Genie 2 decrypts the
  Genie 1 sign-in and GitHub accepts it. No token was ever shown.
- **The release commit, three full suite runs in a row** on the Omarchy test machine, with typecheck, and the
  release-notes check proven to fail when the notes are missing.
- **Windows, on the Windows test machine:** the unit suite, a real terminal with the leak check, a real window and
  the layout at six widths from the build; then the installer built, installed silently with both Start-menu
  shortcuts, the same window checks from the installed app, the sites checks through the front door, and a clean
  uninstall.
