## What’s new

- **Stopping an agent now stops its sidecars,** and offers you a handoff first — the last moment it can be asked what it was doing.
- **One context menu for every agent square.** Start, Restart, Edit, Unmount and Delete, always. “Duplicate” and the move/detach items are gone.
- **`general`, `genie` and `tynn` are no longer usable as agent names.** `general` was never chosen — it was what an unnamed terminal silently became.
- **A remote window now manages the HOST’s agents.** Creating one failed outright; deleting one removed it on your screen while the host kept it.
- **Menus and dialogs are no longer see-through.** Nine of them painted transparent, so the terminal behind read straight through the panel.
- **A host’s agent changes appear live in a remote window,** instead of the roster sitting at whatever it loaded when the window opened.

## Migration

- Agents named `general` holding no terminal are removed. Any still driving one are kept, and are never woken by an upgrade.
- An agent’s driver is now its `tui` everywhere, including the MCP tools. Agents are told to update on restart.
