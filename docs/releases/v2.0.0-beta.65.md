# Genie 2.0.0-beta.65

**Agents no longer get stuck: a hung command can be stopped on its own, and a turn that goes silent ends as Stalled with a way out. Send any file in chat, take back or edit a queued message, and see an agent's plan at a glance. One host now serves every window, phone and device, so Genie is faster and more reliable.**

## What's new

### Chat
- **Send any file to an agent** from the chat, not only images and text.
- **Withdraw or edit a queued message** before it reaches a busy agent.
- **Previews fill the window.** File previews in a question and in the Files viewer have a full-window button.
- **Questions can show visuals:** an agent's question can carry ArtBoard posts, images and HTML mockups.
- **The plan stays in view:** an agent's open plan shows in the chat header and when you hover the agent on the Dashboard.
- **Replies stay apart.** Two replies from an agent show as two messages instead of running together.

### Agents that no longer get stuck
- **A hung command no longer hangs the agent.** The agent view names the command it is waiting on and how long it has run, with **Stop this call**. Only that command ends; the agent is told and carries on.
- **Hung commands time out.** A command that prints nothing for 15 minutes is ended and the agent is told. Change or turn this off in Settings → General → Hung tool call timeout.
- **Silent turns end as Stalled.** A turn whose agent has stopped answering no longer reads Working forever. It shows Stalled with how long it has been quiet, and offers Stop, Restart or Dismiss.
- **Turns an agent starts by itself end properly**, so an agent no longer reads as running for hours after it has finished.

### Layout
- **One header** for workspaces and agents: the tabs on top, with the view's state and actions at the right.
- **The tabs work:** ArtBoard and Storage tabs open their panels.
- **Title bar:** running flows sit beside the view address, and search is an icon.

### Terminals and sites
- **Terminal buttons** in the Agents sidebar and on the Dashboard open a shell in the agent's workspace. The agent's own terminal is in its Settings.
- **The sites bar's »** opens a menu of the sites that do not fit.

### Flows and everything that runs
- **Stop a running flow** from its title-bar pill or the Flows view.
- **Review a run:** the canvas shows each step's outcome, with a step timeline and the run's details.
- **A flow's pill clears** once its prompt reaches the agent, and a prompt to a busy agent is delivered instead of failing.
- **Everything that runs has a log.** Scheduled tasks keep their recent runs with the reason a run failed. Process output survives a restart. Every process has a Log button.
- **Scheduled nudges wake their agent**, the same as mail, instead of failing when the agent was not started.

### Accounts
- **Use another account** is always offered for each provider, in the account popover and in Settings.
- **A sign-in made outside Genie is noticed**, for example a login inside an agent's terminal.
- **Provider stops are explained:** the stop line says in words what the provider said, the agent is told on its next turn, and repeats are counted.

### ArtBoard, Tynn and your phone
- **ArtBoard Clear:** clear decided items, clear everything (pinned too), or delete one item. Cleared items go to .trash with Undo.
- **The Tynn tab's version picker** lists only active and upcoming versions, with readable titles.
- **Phone chat** scrolls, and its messages load as soon as the chat opens.
- **Approvals from a phone or another machine** work reliably.

### Playwright and Proof-of-Done
- **Genie installs the Playwright browsers agents need by itself**, including the versions a project pins, side by side.
- **Playwright works again after an upgrade.**
- **Proof-of-Done cleans up after itself:** a Sign request goes away as soon as its claim is gone, and Genie stops retrying when Tynn turns a check down.

### One host for everything
- **One host serves every window, phone and paired device**, so each sees the same answers whether or not Genie's window is open. Genie is faster and more reliable for it.
- **Typing shows again:** when someone drives your machine, what they type shows in your window as they type.
- **Restoring agents loses nobody**, even if Genie shuts down in the middle.
- **Only the account signed in on a machine owns it.** Shared machines are listed apart.
- **Genie no longer mistakes an unreachable Docker for a missing service.** When Genie cannot read Docker, Services shows why and nothing is changed until it can.

## Known limitations: not in this build

- The rest of the move to one host: further steps are still to come.
- Deployment: only its foundation is in. Deploying from Genie is not.
- Worktrees getting test-only database credentials by default.
- The open pull-request count per workspace on the Dashboard.
- Quitting with things running can still look like a hang.
- A window that cannot reach the host can still wait with no window.
- Two people piloting one machine at once has not been tested live.
- A flow command step's output still includes Genie's started and exited lines.
- Genie Mail, Councils, Slices and Spikes, and the mobile app.
- macOS.
