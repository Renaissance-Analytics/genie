# Genie 2.0.0-beta.22

## What's new

- **The update notice in the header can be clicked.** In beta.20 and beta.21 it sat in the window's drag region, so
  *download* and *restart to install* did nothing — and with no other download button, those builds cannot update
  themselves. **If you are on beta.20 or beta.21, install this build once from this page** (the installer upgrades
  in place and keeps everything); from here on the header notice works.
- **Agents can use Genie's own tools.** In beta.20 and beta.21 an agent Genie started saw its Genie tools (lists,
  AgentInbox, knowledge, imDone, ForceTheQuestion and the rest) but every call was refused — "terminal genie is not
  one Genie knows" — and genie, the workstation agent, could never have been recognised at all. A Genie session is
  now known to Genie by a key the agent cannot overwrite, whatever it passes, and genie is a caller like any other.
  Measured with the owner's own genie agent, on its real conversation: its call answered.
- **Attach files to a message.** Images (PNG, JPEG, GIF, WebP, up to 5 MB) and text files you attach in the chat
  are sent to the agent with your message, for Claude and Codex agents alike. Your message shows the files it carried.
  Anything an agent cannot take — a binary file, an executable, an image over 5 MB — is refused before sending,
  and the message is kept, marked not delivered, with the reason naming the file. Up to 10 files and 40 MB a message.
- **An agent's history is shown, not just this run.** The Agent view and the chat show what the agent did in earlier
  runs — its messages, thoughts, tools and turns, the most recent 3,000 rows — then a "Run started" line, then this
  run. A stopped agent's view is no longer blank. A resumed conversation says so: the agent remembers all of it,
  including anything from before Genie recorded it (Genie 1's history was never recorded by Genie 2). Turn numbers
  carry on instead of starting at 1 again.
- **A shutdown no longer loses an agent's turn.** When Genie quits or upgrades, agents in the middle of a turn — and
  only those — have that turn cancelled, and the next time Genie starts they are resumed and told to check what they
  were changing and carry on. Idle agents are left alone (restored only if *Restore agents on launch* is on).
- **Genie no longer stops your background scripts when it starts.** It cleaned up Genie 1's leftover shells on every
  start, and took any shell whose parent had exited — including scripts you had running in the background. It now
  takes only interactive shells, and only on the one start that imports Genie 1.
- **Doctor mode can look into one workspace or agent, and run one.** `Genie --doctor` still starts with nothing of
  yours loaded. Its genie can now list your workspaces, load one workspace or one agent (its record, persona, agent
  files and recent conversation — reading only), and start that agent on its own conversation with the same tools it
  has in normal Genie, to watch what it does. Starting an agent is refused while normal Genie is running.
- **Each workspace syncs its own agent files.** A workspace's Settings now shows when its agent files were last
  synced and by whom ("at Genie start · 11:54" or "by you · 12:55"), with a Sync now for that workspace alone.
  Workstation settings keep only the four harness switches.

## Migration

Installs over any earlier Genie in place, through the installer. From beta.20 or beta.21 the in-app download does not work (see above), so run the installer once; later updates work from the header.

## Known limitations

- **Files cannot be sent to an agent on another workstation, or to a Take Over window, yet.** Genie says so and
  keeps the message.
- **Claude's reasoning text is not shown.** Current Claude models send their thinking with the text omitted, and
  Claude Code has no documented setting to ask for it in the mode Genie uses.
- **GApps and agents-in-TUIs are not in this build** (the owner's ruling).
- Windows and Linux only; no macOS build.

## How it was verified

- **Every change went red → green** in a Linux test machine (WSL2), never on a developer's desktop.
- **Attachments were measured live** before prism-acp 0.11.0 was released: Claude Code and Codex each described an
  attached image and quoted an attached text file.
- **Agents' use of Genie's tools was measured from the agent's side** in a doctor-mode trial on a real machine: the
  owner's genie agent, resumed on its own conversation, called its lists tool with a made-up id and was answered.
- **The Windows VM** builds the installer, installs it, and drives the installed app.
