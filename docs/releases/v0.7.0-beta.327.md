## What’s new

- **Hibernate a whole workspace:** its agents are asked to hand off, then every terminal, process, site and service stops — and stays stopped through restarts until you wake it.
- **A background process that dies is noticed:** Genie re-checks what it believes is running and brings back what should be, instead of reporting a worker that is gone as healthy.
- **Read why a process stopped:** `manageProcess {action:"logs"}` hands back its last output, so a crash can be read rather than guessed at.
- **A PHP site that 502s names Genie’s own dead worker**, and both ports, instead of suggesting your app bound the wrong one.
- **A site can stop naming two servers:** `command: null` clears it, and Genie says when a stored command is being ignored.
- **Ctrl+Shift+W opens Feedback** for the workspace you are working in.
- **A site stuck on “Starting…” stops** when you press Stop.

## Migration

- **Reinstall PHP in Settings → Toolchain** if you host PHP sites: earlier builds installed a non-thread-safe PHP, and FrankenPHP and Octane need the thread-safe one this build installs.
