# Genie 2.0.0-beta.53

## What's new

### Genie on your phone, over Tailscale
- **One app per workstation.** Install it from `https://<machine>.<tailnet>.ts.net:7421/mobile` with Add to Home Screen. Each workstation becomes its own app, named after it.
- **What's on the phone:**
  - a workspace picker;
  - the workstation dashboard;
  - agent chat with its live stream;
  - a touch file browser and viewer with upload.
- **Photos:** take a photo, or pick one from the gallery, and attach it to a chat. The agent receives it as a real file.
- **Pairing a phone needs the PIN plus Allow on the desktop.** The "Pair this device?" prompt never takes your keyboard focus.
- **A phone that hasn't connected for 90 days has to pair again.** From 14 days before that, a yellow **!** on Settings names the phone and the date.
- **The phone never receives terminal output.** It only gets the agents you open, and it picks up where it left off after sleeping or switching networks.

### Live Tynn board
- **The Tynn tab updates live** as people and agents change the board on tynn.ai: moves, renames, claims, new cards. It catches up after a dropped connection, and an icon shows live or reconnecting.

### Apps and scripts can message agents
- **Who can send:**
  - hosted sites;
  - kept processes;
  - named script keys you create in Settings.
- **Where it goes:** into an agent in the same workspace. Each message is marked with its sender (e.g. `site:flabs@fancy`), and the agent sees it as information, not instructions.
- **Waking:** automated agents wake for it; manual agents see it on their next turn.

### Faster
- **After a restart,** typing no longer stalls for seconds while agents reload their history.
- **Typing while agents are busy:** each agent update redraws only what changed, and your typing comes first.

### Fixes
- **Linux:** Genie's windows now appear on native Wayland, e.g. Hyprland/Omarchy. In earlier Genie 2 builds they never showed up.
- **Agents:** long tool calls (waiting for your approval, for mail, or for a long command) no longer time out in Claude Code after 60 seconds. If the agent goes away, the waiting work is cancelled.
- **Errors:** a part of the window that crashes shows an error card with Retry, instead of blanking the whole window.
- **Sites:** a site shows "running" only once it answers. If it doesn't answer, you see why, with Retry.
- **Hibernate:** hibernating a workspace also stops its services. Waking brings them back.
- **Flows:**
  - a file trigger waits until the file is fully written, and never fires on an empty or half-written file;
  - a scheduled flow runs once per slot.
- **Security:**
  - agents can attach and save inbox files only inside their own workspace;
  - other devices must upload files rather than name a path on this machine.

## Known limitations

- **macOS** isn't supported right now, and no macOS builds are published.
- **The phone app** was verified in a phone-sized browser on a test machine. A real phone over your tailnet still needs a first check.

## How it was verified

- **Tests and CI:** every change merged with its tests failing first, then passing. The full suite passed on the Linux test machine, and main's CI is green on every job, including Windows unit and packaging.
- **Live checks on test machines:**
  - the phone app (30 checks, plus 21 for pairing);
  - the live Tynn board against a test Tynn;
  - app messaging from a site, a process and a script key;
  - Claude Code waits of up to 31 minutes;
  - native Wayland windows;
  - Flows triggers, 20 runs in a row.
