## What’s new

- An agent is no longer tied to the TUI running it. Claude, Codex, Kiwi and the Genie TUI are drivers your agent switches between, and the one it switches away from keeps its conversation running as a sidecar you can flip straight back to.
- Create an agent by right-clicking a workspace in the sidebar. It appears straight away, before it has ever been started.
- Each workspace row now shows who is working there — an avatar stack using the real provider logos, with a hover that gives each agent's active TUI and any live sidecars.
- An agent's purpose and instructions live in `.agents/<name>/AGENT.md`, committed with your project, so the agents you build travel with the repo.
- The Genie OS agent can reach its own tools. It was starting without the MCP tools and skills its instructions told it to use, and now gets the same setup every workspace does.
- Restarting an agent brings the same agent back instead of leaving a duplicate behind.
- A part-typed answer to an agent's question survives closing the panel — your selections and notes are still there when you come back.
- Asking Genie for guidance returns a list of topics you can pick from rather than the entire manual.
- A site setting Genie cannot accept now says so instead of disappearing silently.

## Migration

- Your agents are upgraded automatically and keep their conversations, inboxes and history.
- If a workspace happened to hold two agents with the SAME name under different TUIs, both are kept and flagged — Genie will not choose between them for you, because each has its own conversation. They appear ringed in the sidebar until you decide.
- `.agents/` is now tracked by git so your agents ship with the project; the parts Genie regenerates are ignored for you.
