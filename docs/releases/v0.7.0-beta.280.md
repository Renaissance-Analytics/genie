# Agents that recover cleanly

This release fixes the Genie OS terminal controls, makes agent settings easier to find, and removes the remaining artificial restriction from Tynn workspace imports.

## What’s new

- **Import from Tynn** now lists every accessible Tynn project that is not already linked to a local Genie workspace. Projects no longer disappear because they lack a separately declared repository or an older workspace flag.
- Projects without an envelope repository still enter the interactive workspace wizard, where Genie inspects the local source and builds the correct managed workspace plan.
- AgentPanel context menus now use a solid, theme-aware surface in both light and dark modes.
- The Genie OS flyout keeps the terminal above its dismiss backdrop, so typing reaches the active TUI instead of being intercepted by the overlay.
- **Restart Genie OS** now performs a complete recovery restart: Genie kills the old PTY and its MCP and AgentInbox transports, reads the current provider settings, and starts a fresh terminal. It no longer refuses recovery merely because the wedged TUI never captured a resumable conversation.
- Settings now have dedicated **Agents**, **Network**, and **System** groups. Agent TUI commands and flags moved from the old Tools page to **Agents → Providers**, while MCP controls remain with the rest of the agent configuration.
- **Agents → Genie OSA** now contains the workstation agent’s provider and private backup-repository controls.
- The Genie OSA backup section uses Fancy Git’s repository browser against the real managed `genie-os.agi` directory, rather than displaying placeholder repository content.

## Migration

- No project workspace migration is required.
- Existing Genie OS workspaces and memory are preserved.
- The selected Genie OSA provider takes effect the next time the agent is restarted.
