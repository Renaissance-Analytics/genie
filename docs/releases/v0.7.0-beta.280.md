## What’s new

- **Import from Tynn** now shows every accessible project not already linked to Genie and routes new imports through the workspace wizard.
- Genie OS typing and restart now recover the complete terminal and its agent connections.
- Agent controls are grouped under **Agents**, with separate **Network** and **System** settings.
- Genie OSA backup controls now browse the real managed repository with Fancy Git.

## Migration

- No action is required; existing workspaces and Genie OS memory are preserved.
