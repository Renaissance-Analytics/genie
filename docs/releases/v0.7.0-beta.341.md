## What’s new

- **Share a workspace from its right-click menu.** Create a link, copy it, and watch for whoever connects.
- **A Sharing icon in the header.** Everything you have shared, with revoke on each, and a box to paste someone else's link into.
- **Share a whole workstation.** One link that reaches several workspaces, or the machine.
- **Links expire when you say.** Pick 1, 7, 14 or 30 days — every link used to expire in a week whatever you chose.
- **The Questions and Lists counts show up again.** The numbers were always right; the badge was painting off the button.
- **The question window stops growing.** Opening a file beside a question no longer leaves every later question double-width.
- **A dedicated Redis survives a restart.** Its workspace login used to vanish, taking queue workers and throttled routes with it.

## Migration

- Nothing to do. A Redis container made before this version rebuilds once on first use, keeping its data.
