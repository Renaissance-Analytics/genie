# Genie 2.0.0-beta.28

## What's new

### Databases

- **Postgres with pgvector.** Add Postgres with the `pgvector` variant and the `vector` extension is ready to use. On a
  shared Postgres, Genie creates the extension in each workspace's own database, because a workspace's own login is not
  allowed to.
- **A workspace's own database comes first.** If a workspace has its own engine, its sites and terminals use it instead
  of the shared one. That includes the shared Postgres taken over from Genie 1. You or an agent can choose which engine a
  workspace uses, or detach a shared one. Its data is kept either way.
- **Custom images that are databases.** A custom image can say it is a Postgres, MySQL, MariaDB, Redis or MongoDB. The
  workspace then gets the usual `DB_*` connection settings from it, at its live port.
- **Remove and add back without losing access.** An engine removed with its data kept, then added again, gets its old
  port and its old credentials back, so the data it kept opens with the connection Genie writes.
- **Sites follow database changes without a restart.** Every site start reads the workspace's current connection
  settings. When an engine change alters them, Genie restarts the workspace's running sites itself, so PHP never keeps
  connecting to the old database.

### Sites

- **PHP sites build `https://` links behind Genie's front door.** Laravel apps at `https://<name>.gen` no longer load
  their styles and scripts over plain http and render blank.

### Agents

- **Approval requests appear as toasts.** When an agent asks to add a service or a site, start a process or open a
  terminal, a toast appears on every screen except the Deck, where the same buttons already are. Allow, Deny and Later
  work in place. Several requests stack; scroll the mouse wheel over the stack to go through them.
- **One window for every agent's questions.** Questions from all agents queue in one window that opens for each new one
  unless Do Not Disturb is on. A half-written answer is kept.
- **Agents hear about their mail straight away.** Genie tells an agent it has new AgentInbox mail as soon as it can take
  a turn: at once if it is idle, after its current turn, or once it has started. It does this itself, the same for every
  provider.
- **Codex agents get Genie's tools.** Genie's MCP server now accepts the way Codex connects.
- **Marking a list item Done tells the agent that asked for it.**
- **An agent's sidecar is its own.** Asking for a sidecar rejoins the agent's existing `<name>-slave` instead of creating
  another one.

### Chat

- **Friendlier paste.** Long pasted text becomes a pill you can preview and expand. Pasted images are attached and
  numbered.
- **A quieter footer, and a context meter that tells the truth.** It shows the agent's real context use, and only when
  it is close to the limit.

## Fixes

- Genie's icon shows in the taskbar and the title bar.
- A file opened from Changes shows at once, and a file that cannot be read says so instead of staying blank.
- The doctor window's prompt now sends the files and images you attach.

## Known limitations

- **The UI can lag, and sometimes freezes for several seconds.** The causes are known: blocking process scans when an
  agent starts or stops, the whole chat thread rewritten on every new message, and every streamed token resending the
  agent's history. The fixes are in progress for the next release.
- **Remote and sharing are not yet at Genie 1's level.** Tynn workstation registration and tunnels, workspace and
  workstation sharing, and finding your Tailscale machines are not in this release.
- **Adding a second workspace is not offered in the app yet.** It is only offered while you have none.
- **A Codex agent cannot be sent a message while it is mid-turn.** The message fails instead of waiting for the turn to
  end.

## How it was verified

- **The full unit suite passed** (496 files), with typecheck and the renderer build, in a Linux test machine. Every
  change was written test-first, and each test was watched failing before the fix went in.
- **moic's acceptance passed 42 of 42 checks on the installed app** in the Linux test VM, driven as a real agent through
  Genie's own tools:
  - **https:** a PHP site at `https://<name>.gen` builds only `https://` asset links. A control proves the check would
    count `http://` ones. The assets load through the front door.
  - **Databases:**
    - the workspace's own pgvector Postgres comes first;
    - the site creates the `vector` extension and queries a vector, both from its `.env` and from the settings Genie gives
      it;
    - choosing an engine, detaching and re-attaching all work;
    - a custom pgvector image declared as Postgres works;
    - ports, data and credentials survive a remove and add-back.
  - **Quit:** Genie quits cleanly and leaves nothing running.
- **Windows** was checked in the Windows test VM before tagging. The database checks run on Linux only, because the
  Windows test VM has no Docker.
