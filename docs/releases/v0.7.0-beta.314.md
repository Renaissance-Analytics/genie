## What’s new

- **Light mode is usable again.** The window frame, rail, cards and flyouts were pinned to dark whatever your theme said — putting near-black text on a near-black background.
- **Your lists work over a remote connection.** They live on the host, so a remote window showed nothing. Ticking an item now nudges the agent that wrote it, from wherever you are.
- **Panels missing their background and border have them back**, including the agent cards and the nudge notice. A dormant agent square no longer draws a thick dashed outline.
- **The repo panel’s errors are red again**, and its notices green. Neither colour had ever applied.

## Migration

- Nothing to do. If you run light mode, this is the release worth restarting for.
