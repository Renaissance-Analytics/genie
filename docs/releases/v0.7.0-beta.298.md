## What’s new

- **A real agent manager.** Each agent owns an `AGENT.md` — its system prompt, its rules and its MCP servers in one editable file, instead of a terminal you happened to name.
- **The workstation operator is no longer a pretend workspace.** It boots from a protected `~/.gosa`, outside the reset boundary, so resetting the workstation can no longer take it.
- **It sets up and diagnoses the machine instead of doing your project work.** Four separate surfaces were quietly handing it a project plan and telling it to get started on one.
- **It can triage a stuck agent** and tell you why it is stuck, rather than silently taking the work over itself.
- **Genie Wishes.** A Wish is a Recipe plus the Triggers that start it and the Scope it may touch — the shape of a workflow Genie runs for you.
- **`manageProcess stop` reports what it verified**, not that a signal was sent. A process that outlives the kill is no longer reported as stopped.

## Migration

- Nothing to do. An operator envelope in the app-data folder moves itself to `~/.gosa` once, on first launch.
