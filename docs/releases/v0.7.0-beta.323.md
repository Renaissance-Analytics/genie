## What’s new

- **Agent messages arrive through the agent’s channel instead of being typed into its prompt.** Reminders about unread mail come the same way.
- **A Redis is reported ready only once the password Genie hands out actually works**, so a restart can no longer leave every client failing with WRONGPASS.
- **Service health notices a dead port forward** instead of showing a service green while nothing can reach it.
- **Background processes have their own Processes window**, laid out like the Site Manager, instead of crowding the sidebar.
- **The IssueWatch panel names the open Tynn feedback issues** rather than only counting them.
- **Dismissing a question tells the agent it was dismissed**, not that you gave an empty answer.
- **Built on Electron 44 and the latest release of every dependency.**

## Migration

- Nothing to do. Running agents come back with their channel when this update relaunches them.
