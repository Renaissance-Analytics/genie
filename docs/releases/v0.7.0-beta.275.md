# Genie’s agent workspace release

This release replaces the old terminal-injection approach with a real agent
workspace system and makes Genie Apps first-class development workspaces.

## What’s new

- AgentInbox is now the durable, local agent-to-agent messaging layer. Claude
  Code connects through Channels; Codex connects through app-server. Messages
  are no longer delivered by typing into an agent’s chat input.
- AMS agents are saved workspace agents with durable identity, harness-aware
  startup, persona binding, status, access control, and native AgentInbox
  connectivity checks during automatic boot.
- GApp Development Workspaces can scaffold, validate, preview, and launch an
  app against live source. GApp agents use the workstation’s chosen AI provider.
- ArtBoard now opens artifacts on the Fancy ArtBoard canvas.
- What’s New has a permanent menu entry and shows curated notes for every
  release crossed by an upgrade.
- Workspace and GApp files now carry immutable shared-schema identity so Genie,
  Tynn, Aionima, and future ecosystem tools can update them safely.
- Redis cache clearing is isolated to the workspace-owned cache instead of
  affecting unrelated services.

## Migration

You do not need to migrate before reading or using What’s New. When you choose
to migrate a legacy workspace, open its workspace settings and run the
Interactive Upgrade. Genie creates a timestamped backup before the first
schema-aware write, preserves unknown project.json fields, and refuses to
overwrite a workspace stamped by an unsupported schema revision.

The GApp manifest is `genie-app.json`; it is not `gapp.json`. Existing `.agi`
and `.gapp` envelope folder names are not renamed during migration.
