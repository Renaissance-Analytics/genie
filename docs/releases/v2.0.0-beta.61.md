# Genie 2.0.0-beta.61

**Genie's background service now does the work, so agents keep running whatever the window is doing, and driving another machine finally works. This build also carries every beta.60 fix. Please update.**

## What's new

### Your agents live in the background service
- **Close every window and your agents keep working.** Agents, workspaces, the Tynn board and issues, rate limits and Take over all run in Genie's background service. A window only shows them.
- **If the background service can't start, Genie says so** and offers Try again, Open the log and Quit, so it never runs a second, half-working copy of itself.

### Working on another machine
- **You're in control as soon as you connect** to a drone.
- **Take over** opens the remote agent's TUI in a window on your machine.
- **The folder picker shows the remote machine's files,** starting at its home folder.
- **Share links.** Share a workspace from its strip, or the whole workstation from the title bar.
- **Works with no window open on the other machine,** and you land on its Settings → Remote access with **Disconnect** there.
- **If the other machine's background service restarts,** your window reconnects by itself and you're driving again.

### Agents
- **Claude installed behind a wrapper is found.** If it can't be, Genie names the file and offers **Choose claude.exe**, in the agent's settings and on a failed Start.
- **Antivirus and Codex:** Genie's process helper ships prebuilt and signed, so nothing is compiled on your PC. If antivirus still stops it, the agent names the file and the cause.
- **An agent that doesn't come up within 20 seconds says what it's waiting for,** instead of sitting silent.
- **Stop no longer pauses every agent,** and it ends the tool's processes too.
- **Questions stay visible,** and an updated question is waiting for you straight away.

### Settings and connection
- **Clicking a link in chat no longer breaks the window's connection.** If the connection ever drops, it reconnects by itself, and a change you made meanwhile still applies.
- **The IssueWatch tab** has short labels and no overlapping text, and each change shows Saving, then Saved or the reason with Retry.

### Apps
- **Install, update, turn off and uninstall apps** from the GApp Store, each with a review and your consent first, then **Open** an installed app in its own window.

### Steadier
- **Question updates send only what changed,** agent logs rotate at 64 MB, and opening a file never fails because too many are open.
- **Windows:** a brief file lock no longer stops the background service.

### Sounds
- **New alert sounds,** in themed families.

## Not in this build

- **Genie Mail, Accounts and Compliance.** They're in progress and come in a later beta.
- **Publishing apps to the marketplace.** The registry and the publishing tool exist, but Genie doesn't hold a publisher key yet, so signed packages from the marketplace are refused for now.
- **Some background-service work:** a Pilot doesn't get live Tynn board updates or a drone's rate limits while no window is open on the drone, and sharing from a drone needs a Genie window open there.
- **On a machine you drive with no Genie window open,** its own settings don't show yet ("Open Genie on … to see its settings"), and a Take over window open during its restart doesn't come back by itself.
- **Coming next:** installing apps from the marketplace and app previews, updating the window without restarting agents, the model list refreshing while an agent runs, missed scheduled tasks catching up, one shared Playwright install, and usage and cost reports.
- **macOS** isn't supported right now, and no macOS builds are published.

## Also fixed in this release

- **A trusted workspace stays trusted:** agents' "always allow" choices no longer untrust it, stop its sites or bring approvals back.
- **Crash reports** send with a note (Genie names any word it removes), and a computer restart isn't reported as a crash.
- **A dismissed question stays dismissed,** and any Deck action that's refused says why on the item.
- **The Deck is easier to read:** a short title, numbered steps, clickable links.

## Known limitations

- **Linux keyring:** Genie unlocks a keyring with no password without asking. The password dialog for a protected keyring hasn't been confirmed on a test machine yet.
- **A message already handed to a Claude agent mid-turn** can still run after you stop it.

## How it was verified

Every change landed with a test that failed first. The release commit passed the full CI matrix: Linux and Windows unit suites, the Flows suite, packaged builds for both (the packaged Windows background service now has to actually come up, not only be started), the background service on plain Node, and real-window runs on Linux and Windows.

**Two Windows machines over a private network** (Windows Server 2025, installed builds of the release commit): control on connect, starting and chatting with an agent, Take over, the remote folder picker, forwarded tools, a question surviving a background-service restart, the Share button and its signed-out refusal, and no background-service stall over 1 second.

**Not yet seen on a real machine:** starting a real Claude agent (the test machines have no Claude sign-in), making a real share link, Codex with Defender actively quarantining, the "background service can't start" dialog, opening another workstation's browser window, and Windows 11 itself.
