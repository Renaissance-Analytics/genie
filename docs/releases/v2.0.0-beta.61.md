# Genie 2.0.0-beta.61

**This release brings the new Dashboard, delivers agent mail in full, and adds Tynn's WIP and Issues pages to the Tynn tab. Please update.**

## What's new

### Dashboard
- **One list of every agent, in alphabetical order,** with Workspace and Status columns. Groups are gone.
- **Sleeping and Stopped agents are hidden until you want them.** An agent idle for five minutes or more is Sleeping. A button shows each group, with its count.
- **Each row is coloured by the agent's status.**
- **A hibernated workspace stays out of the way.** Its agents and data no longer appear in lists, the Deck, Flows, Processes, the inbox or Knowledge results. It's only in the sidebar's hibernated view, and waking it brings everything back.

### Agents and mail
- **An agent gets the whole message, not a reminder to check its inbox.** Every sender, time, the full text and attachment names arrive in one prompt.
- **Mail keeps trying until it's delivered.** If an agent can't take a message yet, Genie tries again after 1, 2, 4, 8, 16 and 32 seconds, then every minute.
- **The message card in an agent's chat shows Waiting or Delivered.** If delivery was refused, the reason shows on the card.
- **Interrupting an agent to send a message no longer stops it.** Only "Stop this turn" stops an agent, so new mail still reaches it after an interrupt.
- **Who may message an agent is set on the agent.** The workspace setting "Who may message agents here" is gone. Your existing settings carry over as the stricter of the two, so no agent becomes reachable by more agents than before.

### Tynn tab
- **WIP:** Active, Attention and Done, with each story's tasks. You can claim and step tasks, and the page updates live.
- **Issues:** filter, search, file and edit issues, convert one to a story, resolve or discard with a reason, and see changes live.
- **Page navigation** in tynn.ai's order and with its icons. Only built pages are shown.

### Windows
- **Microsoft's own files keep Microsoft's signature.** Genie, its helpers and the other files that ship unsigned are signed by Renaissance Analytics.
- **Genie's background service only accepts connections from your own account.**
- **A window that comes back after a freeze gets its connections back reliably.**

### Everything else
- **Spreadsheets:** a damaged or oversized workbook can no longer use up memory. If Genie refuses one, it says why instead of showing an empty sheet.
- **Terminals** run through Genie's background service, and each window receives only the output it shows.

## Not in this build
- **Tynn tab:** the VIP, Releases, Home and Features pages. Tynn's side is being built now; they arrive in a following release.
- **Several accounts per provider** and switching between them.
- **Genie's element catalog and plugin SDK, and the marketplace.**
- **The rest of the background-service work:** moving a workspace between workstations, and agents that come along from a Pilot.
- **macOS** isn't supported right now, and no macOS builds are published.

## Known limitations
- **Linux keyring:** Genie unlocks a keyring with no password without asking. The password dialog for a protected keyring hasn't been confirmed on a test machine yet.

## How it was verified

Every change landed with a test that failed first. The release branch passed the full CI matrix on its final head.

**Windows**, on fresh Windows Server 2025 machines, with Genie as a standard user in its own signed-in desktop:
- **Quit keeps your agents:** "Just close the UI" left the background service and the agents running, and "Shut down everything" ended them.
- **The window and the service are separate:** with 11 agents running, the service and all 11 outlived the window, and a new window picked up the same service and agents.
- **The ArtBoard stays responsive:** opening a 2 MB image took 288 ms, and listing 100 posts 256 ms.
- **Safe mode and crash recovery:** a crashed window reloads with your agents still running. After three crashes in ten minutes it stops retrying and offers Restart Genie.
- **The full test suite** ran in that desktop session: 11,980 of 11,981 tests passed. The one that timed out under the full suite's load passed 5 times out of 5 on its own, in 5 to 10 seconds, and it passes on our build machines.
- **Your saved sign-ins:** Windows Credential Manager stored, read back and deleted a key in the signed-in session, a key saved before a restart was still there after it, and right at sign-in it answered within 29 ms with no refusal.

**Signing:** a signed test build of this exact tree (run 42406486629) showed the 11 Microsoft files with Microsoft's signature, and every other Windows binary, the installer and the uninstaller signed by Renaissance Analytics with a timestamp.
