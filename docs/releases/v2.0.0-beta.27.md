# Genie 2.0.0-beta.27

## What's new

### Sites

- **Trusted HTTPS for `.gen` sites.** Genie uses the certificate authority your machine already trusted for Genie 1, so
  `https://<name>.gen` opens with no certificate warning after the upgrade. On a fresh install, Genie asks once.
- **PHP sites know they are served over HTTPS.** Laravel and other PHP apps now build `https://` links, so pages no
  longer load their styles and scripts over plain http and get blocked.
- **No admin prompt when a site starts or stops.** The hosts file lists every site you have set up, not only the ones
  running, so starting and stopping a site changes nothing that needs permission. When something does need it, trusting
  the certificate and updating the hosts file share one prompt. Genie 1's old hosts entries are removed.
- **When another program holds port 443, Genie says which one.** Use Try again once it is free.
- **Names with several parts work,** such as `web.acme.gen`. New sites default to `<folder>.<workspace>`, the way Genie 1
  named them.
- **Each site row has Open, Restart, Edit, Logs and Remove.**
- **Genie's built-in browser opens each site at its own address.** Each site keeps its own cookies, so two Laravel
  apps no longer sign each other out. Back, forward and reload work, and your sites are one click away.
- **Pin a site to a PHP version.** Toolchain installs PHP 8.2 to 8.5 on Windows and checks each download before it is
  used. A version a site uses cannot be removed.
- **Sites keep running through an update.** Genie's web server runs from a copy that installing a new version does not
  replace.

### Services

- **Each workspace gets its own database and login** on a shared Postgres or MySQL, and its own Redis user. The
  connection is written into each site's `.env` and kept up to date. Genie writes the file only when git ignores it, so a
  password never ends up in a commit.
- **Logs for every service,** with passwords hidden.
- **Delete data is refused while another workspace still keeps data in the service,** and Genie names which ones.
- **Mailpit's web inbox opens from the Services tab.**
- **New services:** Meilisearch, S3-compatible storage (each workspace gets its own bucket and keys), WebSockets (each
  workspace gets its own app and `REVERB_*` settings), and any Docker image of your own.
- **Unused services stay stopped.** Genie no longer starts Genie 1's services that no workspace uses.

### Background processes and scheduled tasks

- **A process's output is kept after it exits,** and it shows on the Processes tab.
- **A process that dies is noticed and restarted.**
- **Scheduled flows run.** Use Run now to run one immediately. Each run shows whether it ran, failed (with the reason)
  or was held back. Schedules follow your machine's local time. Genie 1's scheduled tasks are brought over turned off, so
  you choose which ones to turn on.

### Toolchain

- **Install what is missing:** Genie installs it with your system's package manager after you click Install.
- **Check and repair:** Genie fixes the order of tools on Genie's own PATH, gives PHP the certificates it needs for
  outgoing HTTPS, and offers to install a missing Visual C++ runtime. Your own PATH and `php.ini` are never edited.
- **Updates wait for work in progress.** Genie will not update Claude Code or Codex while an agent of that kind is
  working, or Node while anything that uses it is running.

### Agents

- **Agents can manage services, sites and processes** through Genie, and you approve what changes things.
- **Questions from agents:** every question has a notes field, Answer stays disabled until every question has an
  answer, and the question window opens for every question.
- **The Deck, rebuilt.** Everything waiting on you is grouped by workspace, with the agent, the question and its age,
  and you can answer in place. Questions an agent is no longer waiting for are marked stale; dismiss them one at a time
  or all at once. Every question has a notes field, and your notes go to the agent with the answer, or with a dismissal.
- **No more question in the Deck without its window.** Closing the question window used to put away every question
  queued behind it, including ones you had not seen yet. Now only the one on screen is put away, and the next one comes
  straight up.
- **The chat follows you between workspaces.** Moving to another workspace moves the chat to an agent there. If you
  deliberately keep chatting with another workspace's agent, the composer says which workspace it is in.
- **Claude's own commands and skills appear in the chat's `/` menu** and in the agent's settings.
- **A large tool result no longer marks an agent Broken.** An agent that read a big image could show "Broken" while it
  kept working.
- **Closing the window keeps Genie running in the tray.** Quit from the tray, or run `Genie.exe --quit`.

## Fixes

- **Genie no longer freezes behind an invisible error box.** An error in Genie's background work used to open a
  blocking system dialog that, when Genie had no window on screen, nobody could see or close. Such errors now appear on
  the Deck, where you can dismiss them, and Genie keeps running. The error that first caused this, a stop racing a site's
  exit, is fixed too.
- **Agents' requests appear on the Deck the moment they ask.** A request to start a process or add a service could sit
  unseen until something else refreshed the Deck.
- **Quitting with agents running asks first, then quits cleanly.** `Genie.exe --quit` used to end Genie abruptly
  instead, leaving an agent's helper process running.
- **Stopping an agent on Windows stops its whole provider,** not only the command window in front of it.
- **Two flows due at the same time both run.**
- **Claude Code and Codex offer updates on Windows,** and when an update or install is refused, the reason shows on
  that tool's row.
- Quitting Genie no longer leaves a site's `.env` half-written.

## Known limitations

- **Stop under the chat's composer ends the agent, not just its turn.** A Stop that ends only the turn is ready for the
  next beta.
- **`Genie.exe --quit` with agents running waits for you to confirm** "Quit Genie?" instead of quitting straight away.
  Quitting from the tray or the window works as before.
- **Codex agents do not see Genie's tools** (agentinbox, questions, services). Claude agents do.
- **Managed versions are PHP only.** Node, Go and Python come from your PATH. Rust sites and Python apps other than
  Django are not served yet.
- **Claude's reasoning text is not shown.** Current Claude models send their thinking with the text omitted.
- **GApps and agents-in-TUIs are not in this build** (the owner's ruling).
- Windows and Linux only; no macOS build.
