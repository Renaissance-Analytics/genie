## What's new

- **Agents no longer run in terminals.** A managed agent is a structured ACP session. The pty is removed as an agent engine, so nothing can route one into a shell.
- **Restart was typing into a shell too.** The relaunch path had no engine check and typed a resume line every time — the reason agents came back in terminals after beta.2.
- **A pty pin saved on an older agent is ignored.** Specs from before this release carry one; it can no longer bring the terminal path back.
- **Configured launch flags are reported, not silently kept.** ACP cannot carry them, so Genie names what it dropped instead of opening a shell to preserve them.
- **The Genie restart message to agents is gone.** ACP agents reach Genie's services directly and no longer need telling to reconnect.
- **Claude and Codex run as managed agents.** Other providers still work in a terminal you open yourself, with Genie's MCP available.

## Migration

- Existing agents need no edit. Start one and it comes up as a session, not a shell. If a terminal from a previous version is still open, quit Genie and close it.
