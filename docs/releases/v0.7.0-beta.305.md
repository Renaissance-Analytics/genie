## What’s new

- **An unmounted workspace’s agents can be recovered.** Every workspace now has an agent roster that reads the `.agents` files an unmount deliberately keeps, and turns them back into agents.
- **A pending question survives a restart.** Questions are stored, not held in memory, so an upgrade no longer strands an agent waiting on an answer that can never arrive.
- **An interrupted ask rejoins its own question** instead of asking you the same thing twice.
- **Only the driver actually in control** is interrupted by a host’s question. Everyone else still sees it in the questions list — no modal, no chime.
- **One bad settings section no longer kills the Settings window.** Each section now fails in place and says which one it was.
- **A question only links files it can point at.** A bare filename is no longer a link, so it can’t quietly open a same-named file from the wrong repo. The window recentres when the file pane opens.

## Migration

- Nothing to do. Pending questions start being stored from this version; questions already open when you upgrade are not recovered.
