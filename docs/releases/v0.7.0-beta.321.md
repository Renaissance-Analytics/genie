## What’s new

- **Upgrading no longer un-pairs your remote hosts on Linux.** Genie now remembers which keychain backend actually worked and re-asserts it, instead of losing it on every self-restart.
- **"This computer's keychain is unavailable" stops being said about working keychains** — and when there is a real fault, the advice now matches which one it is.
- **Enabling or disabling a hosted site no longer asks to write your hosts file twice.** The hosts block tracks configured sites, not running ones.

## Migration

- Nothing to do. Pair once after upgrading and it should stick.
