# Genie 2.0.0-beta.46

## What's new

### Genie no longer grabs your cursor on every shell command

Since beta.44, every shell command an agent ran (Bash, PowerShell) brought Genie's window to the front and put your cursor in the chat box, even while you were working in another app (#1235).
- **Cause:** the approval check Claude runs before each shell command started a second copy of Genie instead of running the check. Genie now runs the check itself.
- **Approvals now hold:** that same bug meant agents set to **Ask** or **Edits only** were not actually stopped before shell commands. They are now.
- **Only you bring Genie forward:** nothing an agent does can raise or focus a Genie window any more. Opening a file for you or opening a site only flashes Genie's taskbar button. Only your own clicks bring Genie to the front.

### Agents work without Tynn

In beta.45, being signed out of Tynn, or Tynn being unreachable, stopped every agent in a Tynn-linked workspace with **"Sign in to Tynn in Settings"**, and Restart did not bring them back (#1234).
- **Agents always start.** Without Tynn, an agent starts without its Tynn tools, and its chat says Tynn is unavailable.
- **Saved keys work offline.** An agent's own Tynn key is used without asking Tynn first. A key Tynn has revoked is still refused.
- **Signing in brings them back.** When Genie signs in to Tynn again, the affected agents restart by themselves.
- **A hiccup no longer signs you out.** When Tynn turns Genie away, Genie shows signed out but keeps your sign-in and checks again a few times, so a short Tynn outage clears up without you signing in again.

### Flows

- **A file can start a flow:** a file added to a workspace folder can start a flow, filtered by folder, kind and minimum size. A new **Move the file** step moves it within the workspace.
- **A stopped run says where:** a run that failed or was held now shows which step stopped it, and which steps ran or never ran.

### Plugins

- **A plugin tool only gets what it declares:** it can read its own folder, and your workspace only if its manifest asks for files. It can reach only the hosts it lists, and it cannot start other programs.

## Known limitations

- macOS is not supported right now, and no macOS builds are published.
- On Windows, an agent's first start in a Tynn-linked workspace can take a few seconds longer while its key's file permissions are set (#1212, improved in the next release).
- If Tynn keeps turning Genie away through all of its re-checks, Genie stays signed out until you sign in again or the PC wakes from sleep.
- A brand-new agent started while Tynn is unreachable gets its Tynn tools only after the next sign-in or a restart.
