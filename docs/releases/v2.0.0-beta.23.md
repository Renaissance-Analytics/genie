# Genie 2.0.0-beta.23

## What's new

- **A Shells tab: everything an agent has running.** After Changes in an agent's view, a new Shells tab lists what
  the agent is running in the background:
  - background shells, with the command each one runs;
  - Monitor watches and subagents;
  - terminals it opened in the workspace;
  - what has ended (completed, failed or stopped), with Claude's summary and the output file.

  A green count of what is running sits on the tab, so you see it from any tab. Claude Code's own background work
  is listed and marked, but not counted. Codex does not report background tasks, so for a Codex agent the tab lists
  what it started and says its state was not reported. Genie never guesses whether one is still running.
- **Changing an agent's model or tool setting takes effect without restarting it yourself.** Before this, the change
  waited for the agent's next start. Genie now restarts the agent on the same conversation at the first moment
  that costs nothing:
  - an idle agent restarts at once;
  - an agent in the middle of a turn, or waiting on your answer, restarts when the turn ends (your question is
    never cancelled);
  - an agent with background tasks running restarts when they end, because a restart would stop them.

  The note under the setting tells you which of these happened.
- **The settings you pick stay picked.** Choosing a model, a tool setting, a mode or who may message an agent used
  to snap back to the old value on screen, although the new one had been saved.
- **One thought is one row.** A thought used to be broken into a row per fragment ("Found" / "that Genie l" / …),
  and a thought Claude did not send showed as a column of "Reasoning not sent" rows. Each is now one row.
- **The Turns column scrolls.** Turns below the bottom of the window could not be reached before.

## Migration

Installs over any earlier Genie in place. From beta.22 the header's update notice does it. From beta.20 or
beta.21, run the installer once.

## Known limitations

- **Files cannot be sent to an agent on another workstation, or to a Take Over window, yet.** Genie says so and
  keeps the message.
- **Claude's reasoning text is not shown.** Current Claude models send their thinking with the text omitted, and
  Claude Code has no documented setting to ask for it in the mode Genie uses.
- **A background task cannot be stopped from the Shells tab yet.** The tab shows it; stopping it is still the
  agent's job.
- **GApps and agents-in-TUIs are not in this build** (the owner's ruling).
- Windows and Linux only; no macOS build.

## How it was verified

- **Every change went red → green** in a Linux test machine (WSL2), never on a developer's desktop. New code was
  also broken on purpose to prove its tests catch it, then restored.
- **The Shells tab was checked against prism-acp's real mapper** (0.12.0, released for this build): Claude's
  documented background-task messages go through prism-acp and Genie's reader together in one test.
- **The Windows VM** builds the installer, installs it, and drives the installed app.
