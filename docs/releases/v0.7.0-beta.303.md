## What’s new

- **Flows are a canvas, not a form.** They run on fancy-flow now — drag steps, branch, connect. The old recipe dropdown and its twelve-operator filter language are gone.
- **One Flows system, three scopes.** A flow is `system`, `workspace` or `gapp`; a GApp flow is just one whose scope says so. Arming states exactly what it may do and where.
- **Genie’s own steps are on the canvas** — terminals, agents, workspaces, sites — alongside fancy-flow’s. Agents can author flows, and can never arm one.
- **Installing a CLI is no longer blocked by an unrelated busy agent.** A mid-turn Claude was stopping installs of tools it had never run. Installing something you do not have replaces nothing.
- **A dead terminal can be restarted.** Genie used to refuse when there was no conversation to resume — including when there was none at all. Restart now offers a fresh start.
- **New workspace asks for a name.** Importing from Tynn stops asking for a folder, a repo-less project gets a workspace, and a `.agi` container is a convenience that gates nothing.

## Migration

- Existing Flows are removed. Each referenced the one built-in recipe, and all were switched off; the same behaviour ships as a template you can open, read and turn on.
