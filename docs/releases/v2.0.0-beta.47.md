# Genie 2.0.0-beta.47

## What's new

### Restart brings an agent back, from any state

Restart used to be scattered across many buttons that did different things, and several of them could never work: on a **Broken** agent, Restart was always refused (#1238).
- **One Restart, everywhere.** Every Restart and Start button (agent view, Dashboard, chat, phone, tray, Deck) now does the same thing.
- **Works from any state:** running, idle, Broken, stopped, signed out or never started. A Broken agent now starts again on the same conversation instead of being refused.
- **Nothing owed is lost.** After a restart, the agent receives everything still waiting for it, in order and once: the "Genie restarted, carry on" message after an upgrade, and any message that was not delivered. Before, these could be dropped for good, so an agent came back not knowing it had been interrupted.
- **A cut turn carries on.** If Restart interrupts an agent mid-turn, the agent is told and continues where it was.
- **Fewer buttons:** duplicate restart buttons are gone. **Restart fresh**, which deliberately starts a new conversation, stays in the ⋯ menu.

### Faster first start on Windows

In a Tynn-linked workspace, an agent's first start sets permissions on its private Tynn key. That now uses far fewer background calls, so the first agent is ready in roughly 20–30 seconds on the test machine instead of about a minute or more (#1212).

## Known limitations

- macOS is not supported right now, and no macOS builds are published.
- Flows are still a list rather than fancy-flow's canvas editor. The canvas, and Genie 1's scheduled commands moving into workspace background processes, are in progress (#1204).
- If Tynn keeps turning Genie away through all of its re-checks, Genie stays signed out until you sign in again or the PC wakes from sleep.
