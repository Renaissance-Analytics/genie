## What’s new

- **Status dots are round again outside the main window.** In Settings they were drawing as squares — the same rule, missing a value it could only see in the master window.
- **The copy button on code blocks animates again** everywhere, not only in the main window.
- **Colours that never applied now do.** Another 17 style rules were being dropped whole because they read a value that was never defined.
- **A workspace opened from the tray, the Add Workspace dialog or an agent now starts its WebSockets** instead of leaving them dark until a site starts.

## Migration

- Nothing to do. Switching workspaces inside the main window does not start them yet — that follows in the next release (#597).
