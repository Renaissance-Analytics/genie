# Genie 2.0.0-beta.42

## What's new

### Your messages wait for Codex

- Input sent while a Codex agent is working appears in chat immediately as **Queued**, then reaches the agent in
  order as its turns end. Your words, sender and attached images are kept together.
- Stopping the current turn keeps queued messages. Stopping the agent, or a failed run, keeps unsent messages as
  drafts with **Restart and send**, **Send now** and **Discard**. Those drafts survive reopening Genie.
- Local and remote chats use the same queue. A failed send keeps your text and says why. Claude continues accepting
  messages during its turn.
- A provider rate limit or overload keeps input in that queue too. Chat says it is waiting for the provider to
  resume; the messages then reach Codex in order. Stopping while paused keeps every unsent item as a draft.

### Provider overloads recover automatically

- When the provider reports that it is overloaded, Genie waits and retries after 30 seconds, then 1, 2 and 4 minutes.
  If it remains overloaded after those retries, the agent shows the failure reason.

### Updated components

- Updated the provider bridge to prism-acp 0.24.0, the MCP server to 0.3.1 and the shared UI components to 5.59.0.
- Updated Electron to 45 and the TypeScript, Vite and Vitest build tools.

## Known limitations

- Several screens still recompute over an agent's whole history on each update; very long histories can still be
  noticeable.
- macOS builds are not published in this beta.
