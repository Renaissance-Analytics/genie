# Genie 2.0.0-beta.32

## What's new

### The chat stays open

- **The chat is always open, beside the page, never on top of it.** There is no close button. It follows what you're
  looking at: a workspace chats with its default agent, an agent's tab with that agent, every other screen with
  Genie. Its conversation is there on every page.
- **Ctrl+J** puts you in the chat, and **Tab** accepts the highlighted `/` or `@` suggestion.
- **/compact** now finishes as done and says how much it compacted.

### Workspaces

- **The sidebar lists workspaces**, each with Genie 1's indicators: a pulse while its agents work, and its processes
  and sites, which open their settings.
- **Each workspace has a Dashboard**: what its running agents are doing now, what waits on you, and the turns that
  just finished.
- **Each workspace has one default agent**, chosen in its settings. It can ask to create another agent for the
  workspace, and you approve it. The separate "-slave" helper agents are gone (existing ones stay as ordinary agents).
- **An agent's page shows its Active Plan** beside the chat.
- **Addresses read as places:** `genie://<computer>/<workspace>/<tab>`.

### Settings

- **Workstation settings are Genie 1's:** grouped sections in a sidebar, one page each.
- **A workspace's settings are its own page**, and an agent's settings name its provider.

### Signing in to Tynn

- **Signing in to Tynn works the way Genie 1 did:** in your browser, back to Genie by link, or by pasting the code.
  There is no token field. **From Tynn** offers your own projects.

### Remote computers and sharing

- **Remote access is off until you switch it on.** On Windows, switching it on adds its firewall rule.
- **Computers you've connected to are remembered,** and each one opens in its own window, with Reconnect and Forget.
- **Tailscale from Genie:** where it stands, Install, Connect and Sign in.
- **This computer can join your Tynn network:** it registers with Tynn, and your other computers find it under
  **Connect** and open it over the Tynn relay, without Tailscale.
- **Share a workspace, or this whole computer, through Tynn:** a link with control or read-only access, an expiry,
  and a list of links you can revoke. Whoever opens it signs in to Tynn and reaches only what the link allows.
- **Upgrade a remote computer's Genie from here** when it's yours.

### Files

- **The editor fills its pane and saves with Ctrl+S.** Unsaved changes show a dot, and a save that fails says why.
- **Right-click a file or a tab:** Open in external editor, Reveal in file manager, Copy path, and the tab's Close
  options. **In the tree:** New file, New folder, Rename, Duplicate and Delete. Delete moves it to the trash, and
  nothing is ever overwritten.
- **Folders load when you open them,** so big workspaces stay fast at any depth.
- **Every file and folder picker browses the computer the window is driving,** not the one you're sitting at:
  adding a workspace, cloning, locating a repo, alert sounds, attachments, and **Browse…** beside every folder field.

### Questions and sounds

- **A question that names files shows them** in a drawer beside it, as Genie 1 did. Clicking a picked option again
  clears it.
- **Sounds play again.** In beta.31 none of them did.

### Omarchy

- **Genie can encrypt again on Omarchy (Hyprland),** so signing in to Tynn works there.
- **genie gets what Omarchy gives agents:** its skills and the Omarchy command center.

## Known limitations

- **Installing and choosing versions of PHP, Node, Python, Go, Ruby, Java, .NET and Rust** from the Toolchain is
  still to come; this release groups the tools and updates them.
- **Signing in to an agent provider is done in the provider's own window.** Genie knows the commands for Claude Code
  and Codex; for any other provider the window opens its program and tells you what to type.
- **After Genie updates its own tools, running agents aren't restarted yet,** and the host and client are still one
  build. Both come in a later beta.
- **A window driving another computer doesn't play the per-action sounds yet.** The computer's own window does.
- **On some Linux desktops the menu's own shortcuts don't fire.** Genie's keys (Ctrl+K, Ctrl+, F5 and your prompts'
  keys) work everywhere.
- **The window can still freeze briefly when an agent starts or stops.** The fix is planned.
- **PHP sites run on php-cgi.** FrankenPHP and Laravel Octane are planned.
- **The Knowledge Graph editor from Genie 1 is not in Genie 2 yet.**
- **An agent that is already running keeps the service variables it started with.** It gets new ones from
  `services exec` or after a restart.

## How it was verified

- **Two real computers, end to end:** a Linux host on Omarchy and a Windows client, each a dedicated test machine.
  Tailscale connect and upgrade-from-here, then the Tynn network: the host registered with Tynn and became reachable
  over the Tynn relay; the client listed it under Connect, opened it and drove it; the host made a read-only link,
  and a second Tynn account accepted it on tynn.ai, found the computer and was let in. 14 of 14 checks passed.
- **Every change was written test-first,** its test watched failing before the fix went in, and it passed all eight
  checks before it merged, including a real Genie window on Linux and on Windows.
- **The release commit, three full suite runs in a row** on the Omarchy test machine (622 of 622 files each time),
  with typecheck, and the release-notes check proven to fail when the notes are missing.
- **Windows, on the Windows test machine:** the unit suite (4245 tests), a real terminal with the leak check green, a
  real window and the layout at six widths from the build; then the installer built, installed silently with both
  Start-menu shortcuts, the same window checks from the installed app, nine checks of sites through the front door
  (before and after a restart), and a clean uninstall.
