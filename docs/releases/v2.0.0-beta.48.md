# Genie 2.0.0-beta.48

## What's new

### Flows are workflows again

- **The canvas:** opening a flow opens fancy-flow's editor in its own window. Errors show on the node itself, and a flow that can't run can't be saved.
- **Genie's tools as steps:** terminals, background processes, sites, services, knowledge, issues, inbox, questions and more, each following the same approval rules as an agent.
- **Questions wait for your answer** and the flow branches on the option you pick.
- **A run cut off by quitting Genie resumes,** if the step it reached is safe to repeat.
- **Genie 1's flows are imported** as canvas flows, disarmed.
- **Fixed:** schedules dropped from the palette ran in UTC; a run could be lost at the spring clock change; a Wait could end early.

### Scheduled tasks

Genie 1's scheduled tasks are background processes with a schedule again, in Hosting → Processes, not flows.

### Agents

- **Every agent you didn't stop comes back after an upgrade,** including ones that were Broken.
- **No false "carry on":** an agent that was only started, never prompted, is not told to continue a turn.
- **Codex agents restart fast:** Genie no longer replays their whole history, and old "context compacted" floods are collapsed.
- **Shell approvals fail closed:** a permission check that gets no answer now blocks the command.

### Chat

- **Each chat keeps its own draft,** including through a Genie restart.
- **Copy blocks:** code and tables get a copy button. Agents can hand you a `<result>` card that copies with its formatting, so it pastes cleanly into email or documents. Every copy goes through Genie's own clipboard and says when it fails.
- **Replies fill in as they stream,** cards included, with no half-written tags.
- **Agent actions never move your view:** when an agent opens a file, a tab or a site, that workspace's row pulses until you go there.

### Smaller things

- **Plan column:** drag to resize. The chat icon on a step drops it into the chat as a pill.
- **Provider logos** replace provider names.
- **Rate limits:** hover a provider's pill for every limit and when it resets. A dot on the sidebar turns yellow at 30% left and red at 10%.
- **ArtBoard:** cards fill the panel, and Approve / Reject show only when the agent asks for your verdict.
- **File browser:** Export… saves a file anywhere on this machine.
- **GitHub:** organization repositories are created with your own GitHub sign-in. If a permission is missing, Genie says which one and links to the fix.

## Known limitations

- macOS is not supported right now, and no macOS builds are published.
- Connecting to your other machines (workstations) is being reworked in the next release.
- Exporting a whole folder isn't available yet.
