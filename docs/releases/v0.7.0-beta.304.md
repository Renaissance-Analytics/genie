## What’s new

- **The question modal is wider, and fits its window.** No card inside a square frame, and a long question grows the window instead of scrolling inside a second scrollbar.
- **A question that names a file opens it.** Paths a question mentions are clickable and read in a pane beside it, resolved inside that workspace only.
- **ArtBoard verdicts reach the agent again.** Approving or rejecting a post was recorded and then delivered nowhere, because no post ever stored the terminal to reply to.
- **The ArtBoard can be closed.** Zooming an artifact left no way back — dismissing it reopened on the next render.
- **The Flows canvas only offers steps that run.** Kinds Genie refuses are filtered out of the palette rather than accepted and then hung on.
- **The System Workspace answers to remote connections.** Paired devices on Tailscale can drive the Host Genie OSA; it was filtered out of every remote listing.
