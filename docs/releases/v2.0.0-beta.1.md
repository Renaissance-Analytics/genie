## What’s new

- **Genie 2 starts here.** An early look at the Deck — everything waiting on you, every agent, and what happened while you were away — reachable now with `?view=deck`. The grid is still the default.
- **⌘K / Ctrl+K opens anywhere.** It used to need a focused terminal, and it now finds Genie’s own features — Hosts, Sharing, Knowledge, Flows, the App Store — not just workspaces and prompts.
- **Settings stops being shoved behind the main window.** Something running `genie --version` in the background was pulling the main window forward as if you had clicked the icon.
- **An agent’s question no longer steals your keyboard.** You can keep typing where you were; the question waits instead of grabbing focus mid-sentence.
- **Newly installed CLIs work without restarting Genie**, and `gh` is now managed in the toolchain alongside the others.
- **A private agent stays repliable.** Its permission used to decay, so a conversation you were in the middle of quietly stopped accepting replies.
- **Security and hosting.** A critical Next advisory is closed, and a managed PHP site gets verified Redis extensions chosen for the runtime actually serving it.

## Migration

- Nothing to do. The Deck and the new agent surfaces are additive — your Floor, panels, layouts and agents are untouched, and the grid remains what opens.
