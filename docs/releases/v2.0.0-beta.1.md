## What's new

- **Agents can actually work.** An agent on the new protocol was having every file edit refused — it could talk but not act. Fixed. Check this first if 2.0 felt inert.
- **Genie 2: the Deck is what opens** — everything waiting on you, every agent, what happened while you were away. The title bar's eight icons are gone; their signals sit here.
- **A Workflow Dashboard.** One row per agent across every workspace: status, what it is working toward, and the last thing it actually produced.
- **Agents have their own screen, with a Stream.** Every thought, tool call and edit, one line each; open one for its arguments and result. Reasoning never pushes the page around.
- **Chat is a flyout you can pin.** Reach any agent from anywhere, and answer approvals in the thread. Pinned, it reserves the gutter instead of covering your work.
- **Tynn is optional.** Everything local works signed out; Tynn-backed features say what they need instead of holding the whole app behind a sign-in.
- **Two critical security advisories closed**, in the library Genie uses for every clone, commit and plugin install.
