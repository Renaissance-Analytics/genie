# Genie 2.0.0-beta.36

beta.36 is beta.35 for every platform: beta.35 published for Linux only, because a test in its Windows build expected Unix line endings (genie#1101). The app is the same; everything below is new since beta.34.

## What's fixed

### Quitting keeps your agents' last words

- **Nothing an agent just wrote is lost when you quit.** Genie used to exit with an agent's last messages still being
  saved, so they never reached the thread, and a stale lock could stall the next start. Quit now waits for those
  writes (at most a few seconds) before Genie closes.
- **Every process Genie supervises is stopped first** when you quit, before anything else is waited on.

### No more nudges while an agent waits on its own work

- **An automated agent isn't nudged to carry on while its background work is still running.** It reads
  **Working · N in the background**, not Idle.

### The context meter

- **The context meter drops as soon as a conversation is compacted**, instead of showing the old figure until the
  turn ends.

### Chat

- **Your message keeps its line breaks.**
- **Pasted text of 200 characters or more becomes a pill** you can preview, and a pasted image's pill shows a
  thumbnail.
- **The agent's thinking shows in the chat, collapsed.**

### Adding a workspace

- **New workspace makes its real first commit,** as it says it does: a `main` branch, a README, AGENTS.md, CLAUDE.md
  and a `.gitignore` that keeps `sandbox/`, `.trash/` and `.mcp.json` out of git.
- **Import from Git also clones the repo's submodules,** private ones included.
- **The confirm button shows Cloning… / Creating… while it works,** so a second click can't start a second add, and
  after Open existing folder, Import from Git or Import from Tynn, the new workspace opens.
- **A folder name with a dot keeps it** (`foo.agi` stays `foo.agi`), and Import from Tynn makes `<name>.agi`.
- **New workspace can link to one of your Tynn projects** (optional), and says honestly where the workspace is kept.
- **Import from Tynn brings the project's content:** it clones the project's `.agi` workspace when it has one, or builds
  one with the project's repositories as submodules on their own branches. A project you have already added opens
  its workspace instead of being cloned twice.
- **A workspace linked to Tynn gets its Tynn agent connection:** Genie mints the agent token and writes the `tynn`
  server into the workspace's MCP config (kept out of git), so its agents can reach Tynn.

### IssueWatch

- **IssueWatch connects to Tynn's own realtime server** (Tynn moved to Laravel Cloud's), not to Pusher.
- **A long list arrives whole,** instead of being dropped.

### Services and hosting

- **Redis is always its workspace's own and survives a crash** (append-only).
- **Postgres 18** is offered, with its data kept where its image expects it.
- **Genie's own records are written durably**, so a power cut can't leave one half-written.
- **A site's server isn't listed as a background process.**
- **Genie's blocks in the hosts file are always Genie's to replace,** so a stale one can't linger.
- **PHP sites run four workers each, with opcache on Genie's PHP** — faster, and concurrent.

## What's new

### Choose your agent's model from what your provider actually offers

- **The model picker lists your provider's own models**, from the CLI you're signed in to — Fable included, shown as
  "Fable → claude-fable-5-1" — with the default marked and the model in use labelled.
- **Changing a running agent's model switches it in place**: at once on Claude, from the next turn on Codex. No
  restart.
- If the list can't be fetched, you can still type any model name the provider accepts.

### GitHub panel

- **Choose which repos feed IssueWatch** ("Watched repos"), as in Genie 1.
- **Readable by repo**, with how old the reading is and a **Refresh** button.

### Claude Design login

- **When an agent needs Claude Design**, its header, chat and Dashboard row offer **Log in to Claude Design**. It
  opens a window to run `/design-login`; when you close it, the agents that were waiting are told to retry.

### Agents and pages

- **Agents can drive pages on your Genie sites** (the `pages` tool) when you allow it with the new **May drive pages**
  switch; submitting or clicking still asks you.
- **Agents can manage the workspace's tabs** (the `workspaceTabs` tool), by a per-agent switch.
- **Agents can make the flows they need** (the `flows` tool): an agent creates a flow, and only you arm it.

### The Genie browser

- **The Genie browser is its own window again**, as in Genie 1, and a window driving a Tynn workstation browses that
  workstation's sites. **Mailpit's inbox opens at mail.gen.**
- **Site panels in a workspace are live pages.**

### Workspaces

- **Files is a tab of its own.** **The Dashboard is a lane per agent** with a live heartbeat.
- **The Active Plan column collapses** from a button at the end of the workspace tab row.
- **Shells limits per workspace** for terminals and background processes.
- **The file editor is at Genie 1's level,** and Genie 1's **Repository** and **ArtBoard** panels are back.
- **Toolchain lives in Settings.**

### Releases close what they fix

- **Each release comments "Shipped in vX" on the issues it fixes and closes them.**

## Security

- **A shared-workspace guest receives only its own workspace's updates.**

## Known limitations

- **Add workspace is not yet fully at Genie 1's level:** Genie can't yet create a GitHub repository for a new
  workspace or fork one (a GitHub repository stays optional — local-only workspaces are first-class), Import from Git
  takes a URL rather than letting you browse your repos, and Open existing folder / Import from Git write Genie's files
  into your repo rather than building a separate `.agi` workspace around it. These are next.
- **All of a workspace's agents share one Tynn agent token for now;** each agent getting its own (as a Tynn agent) is
  next.
- macOS builds are not published in this beta.
