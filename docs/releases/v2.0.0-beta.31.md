# Genie 2.0.0-beta.31

## What's new

### A new look

- **Genie has a new logo:** the lamp with a terminal prompt. It's on the installer, the taskbar, the window, the tray
  and the title bar.

### The chat follows you

- **No more chat tabs.** The chat now follows what you're looking at: an agent's page chats with that agent, a
  workspace chats with that workspace's agent (the one you last talked to there), and every other screen chats with
  Genie. A workspace's own agent tabs are how you pick an agent.
- **The pinned chat is the only chat.** When it's closed, one button on the right edge opens it on the right agent.

### Signing in to Claude and Codex

- **A signed-out agent says so.** If Claude Code or Codex says your login isn't valid, the agent shows
  **Signed out · log in to continue** on its page, in the chat, on the Dashboard and in the tray, instead of
  "Broken".
- **One click to sign back in.** **Log in to Claude Code** (or Codex) opens the provider's own sign-in in a window of
  its own, with the steps written at the top. When you've signed in and closed it, Genie checks the login and brings
  your signed-out agents back where they left off.

### IssueWatch: GitHub, told to your agents

- **Your agents hear what happens on GitHub:** new issues and pull requests, comments, reviews, pushes and CI
  results on the repositories you watch, delivered like mail.
- **Choose what each agent hears** in its settings, and see it all yourself in a workspace's **GitHub** tab.
- **Agents can ask for the latest** at any time, and Tynn reads GitHub again on request.
- **Feedback is GitHub issues now.** The separate Feedback window is gone; issues on your repositories are tracked by
  IssueWatch.

### Turns, the Stream and the Deck

- **Turns are numbered 1, 2, 3 in order, everywhere,** including agents whose history had repeated numbers.
- **The session strip is readable:** turn labels only where there's room (point at any turn to see its number),
  **Next edit** is a button that jumps to the next edit, and the edit / thought / tool legend filters the Stream.
- **Long Deck items show their first line;** click **Show all** to read the rest.
- **What you're asked to do in the Deck is complete:** every step, with the exact names and values, never "see this
  file".

### Terminals

- **File paths in a terminal open in Genie's file panel,** at the line.
- **Links in a terminal are clickable** and open in your browser, as do links anywhere in Genie.
- **Closing a terminal that's still running asks first.**
- **New scratch terminal** in the tray opens a shell in your home folder, in its own window.

### Updates and help

- **See what's in an update before you take it.** Click the update button in the header: a window lists every
  version since yours, newest first, each with its own notes, and has the button that downloads or installs it. If
  the notes can't be fetched (offline), it says so, and the update is still safe to install.
- **What's new, once per version,** in the release's own words, and again from **Help**.
- **The tray leads with an update on offer,** and opens the Task Manager.
- **The window's header shows the version you're running,** and **Help → Genie documentation** opens the docs.

### Rate limits and sounds

- **A turn that ends on the rate limit always pauses,** even when the provider gave no warning first. The tray and
  your phone say which login is paused, with **Resume now**.
- **Do not disturb** silences Genie's sounds (questions can still chime if you want them to).
- **More things have sounds:** a process exiting, a site or service starting, flows, GitHub events, messages between
  agents, and an agent finishing.

### More

- **The Toolchain is grouped by type** (languages, package managers, version control, containers, agent CLIs), with
  **Update** on every installed tool and no more "unknown".
- **Codex agents can use Genie's tools,** and a subagent's tool calls show their names.
- **The sidebar lists the agents of the workspace you're in.**
- **Files open at the line the agent named,** and big folders in the file tree stay fast.

## Known limitations

- **Coming from beta.30, the notes appear after you update,** in What's new: beta.30's update button can't show them.
  From this version on, the update window shows them before you install.
- **Installing and choosing versions of PHP, Node, Python, Go, Ruby, Java, .NET and Rust** from the Toolchain is the
  next step; this release groups the tools and updates them.
- **Signing in is done in the provider's own window.** Genie knows the commands for Claude Code and Codex; for any
  other provider the window opens its program and tells you what to type.
- **After Genie updates its own tools, running agents aren't restarted yet.** That, with separate host and client
  builds, comes in the next beta.
- **A window driving another computer doesn't play the per-action sounds yet.** The computer's own window does.
- **On some Linux desktops the menu's own shortcuts don't fire.** Genie's keys (Ctrl+K, Ctrl+, F5 and your prompts'
  keys) work everywhere.
- **The window can still freeze briefly when an agent starts or stops.** The fix is planned.
- **Remote and sharing are not yet at Genie 1's level:** Tynn workstation registration and tunnels, workspace and
  workstation sharing, and finding your Tailscale machines.
- **Adding a workspace offers a folder only for now.** Genie 1's other ways (new, from Git, from Tynn) are planned.
- **PHP sites run on php-cgi.** FrankenPHP and Laravel Octane are planned.
- **The Knowledge Graph editor from Genie 1 is not in Genie 2 yet.**
- **An agent that is already running keeps the service variables it started with.** It gets new ones from
  `services exec` or after a restart.

## How it was verified

- **Linux: on Omarchy,** the desktop this release is used on — a dedicated Omarchy 4.0.5 (Hyprland) test machine,
  installed unattended and restored to a clean state before every run. The full unit suite, typecheck and the
  renderer build passed there. Every change was written test-first and its test watched failing before the fix
  went in.
- **Every change passed all eight checks before it merged,** including a real Genie window on Linux and on Windows.
- **Signing in, measured against the real CLIs** on a machine that had never signed in: `claude auth status` and
  `codex login status` both report signed out (exit 1), and a signed-out Claude turn reports
  `authentication_failed` — what Genie reads as Signed out.
- **The release commit, three full suite runs in a row** on the Omarchy machine (573 of 573 files each time), with
  typecheck, and the release-notes check proven to fail when the notes are missing.
- **Windows, on the Windows test machine:** the unit suite (3804 tests), a real terminal, a real window and the layout
  at six widths from the build; then the installer built and signed, installed silently with both Start-menu
  shortcuts, the same window checks from the installed app, nine checks of sites through the front door (before and
  after a restart), and a clean uninstall.
