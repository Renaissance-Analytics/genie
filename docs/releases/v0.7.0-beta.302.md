## What’s new

- **Genie installs agent CLIs, and the Install button works at all.** It was unreachable code: a missing tool produced no row, so nothing could ever offer to install it.
- **Twenty agent CLIs, each a provider you can launch** — Claude Code, Codex, Gemini, opencode, Copilot, Amp, Crush, Qwen, Kimi, Kilo, Cline, Continue, Auggie, Droid, iFlow, Codebuff, Cody and more.
- **The Genie TUI installs.** It had no build, the wrong binary name, a package that shipped empty, and it crashed on every launch. All four are fixed.
- **“Kiwi Code” was never a real product.** The provider could never resolve. It is Kilo Code, with a working install.
- **A CLI Genie cannot install says why**, instead of hiding or offering a button that fails. One it never checks for claims nothing about your machine.
- **New workspace just asks for a name.** It used to open the folder-conversion wizard, which still runs when you open an existing folder or import a repo.
- **A restarted agent is told it was restarted**, reconnects, and confirms it — instead of coming back cold on the previous conversation.

## Migration

- If you had selected the Kiwi Code agent, it becomes Kilo Code and keeps your flags. The stored command is dropped, because `kiwi` was never a binary.
