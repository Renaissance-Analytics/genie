# Genie 2.0.0-beta.55

## What's new

### Genie no longer freezes while it checks Docker
- **What the stall log showed:** Genie's own stall log named the freezes. Every Docker status check started a new process on the window's main thread, and on Windows starting a process can hold that thread for seconds. One session had 216 of these, about 10 minutes frozen in total, the longest 18 seconds.
- **Processes start elsewhere now:** a separate helper process starts every Docker command, Docker's change feed, and every site process. The window's main thread starts none of them.
- **Fewer Docker checks:** Genie now listens for Docker's own change notices and re-checks only when something changed, with a fallback check once a minute.
- **If the helper stops,** its sites come back in a few seconds, with nothing left running behind.

### Sites come back by themselves after a restart
- **Slow starts:** a site that starts slowly shows **still starting** and turns green and reachable as soon as it answers. You don't have to press Retry any more. With ten sites starting together on a test machine, all ten now come up.
- **What "failed" means:** **failed** now means the process really stopped, or gave no answer for 3 minutes. Even then, a later answer brings it back.
- **Site buttons:** they show what's happening, step by step, and a second click joins the action already running instead of starting another.
- **The Hosting panel:** it updates as soon as a site's state changes. It used to lag by about a minute.

### Safer remote connections
- **Pairing:** a guest who joined through a share link can no longer pair a device or become an owner.
- **What guests see:** guests never receive the pairing PIN or the list of paired devices.
- **Drones:** a Drone cannot connect out to other workstations.
- **Sessions:** a connection no longer drops after 15 minutes.
- **Share links:** you can revoke a share link that has already been used, and the guest is disconnected right away.
- **Old local share link:** removed, since nothing could use it any more.

### Chat and inbox
- **Queued messages:** a message waiting for the agent's current step shows a clock and the tool's name, for example `playwright`, instead of a long internal tool id. **Interrupt and send** is still there.
- **Inbox order and search:** the newest messages are on top by default, with one button to flip the order. Search covers the whole conversation, including messages not loaded yet.
- **Answers to your questions:** in an inbox answer, the question id is a link. Click it to see the questions exactly as you were asked them, with your choices ticked.

### Buttons look like buttons
- **What changed:** about 250 buttons and links across the Dashboard, Agent view, Files, Settings, Toolchain, Services, Processes, Schedule, Flows, Hosting, chat and inbox now use the same button design. They show a pointer and a busy state while working.
- **The stream:** "Following live" is now plain status, not a button lookalike. The button that jumps back to the latest output is a real button.

### Fixes
- **PHP 8.5** now installs on Windows.

## Known limitations

- **macOS** isn't supported right now, and no macOS builds are published.
- **Terminal shells:** your own terminal tabs still start from the window's main thread. They move out in a later release.
- **Freeze check:** if Genie ever freezes, `~/.genie/runtime/lifecycle.log` records what it was doing.

## How it was verified

- **Tests and CI:** every change merged with its tests failing first, then passing. Main's CI is green on every job, including the Windows tests and both installer builds.
- **The combined release commit:** its full test suite ran on the Linux and Windows test machines.
- **Freezes:** a test with a deliberately slow 5-second Docker held the window's main thread for 5 seconds before the change, and under 50 ms after it.
- **Sites:** ten PHP sites starting together on the Windows test machine reached 0 of 10 running before the change, and 10 of 10 after.
