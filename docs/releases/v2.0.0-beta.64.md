# Genie 2.0.0-beta.64

**Switch accounts when one runs low, in one click. Save your whole workspace to its repo so a clone comes back complete. Rate limits pause work instead of dropping it, remote sessions show both sides who is there, and an agent's site change never raises an admin prompt without asking you.**

## What's new

- **No surprise admin prompts.** An agent adding or changing a site no longer raises a Windows administrator prompt on its own. Genie asks you first with Approve, Not now or Copy the block, and agents can change sites and services only in a trusted workspace. Please update.
- **Switch accounts when one runs low.** As an account nears its limit, Genie offers to switch. One click opens the provider's own sign-in with steps on screen, and every agent carries on with the new account. If the sign-in fails, nothing changes.
- **See your accounts at a glance.** A chip in the header names the signed-in account. Its popover lists every account you have used, with plan, usage bars and local reset times, and switches with one click.
- **Settings → Accounts** lists your accounts with their usage. You can switch, rename or forget one, and choose which limit windows (5-hour, weekly or both) trigger an offer. Your accounts, the active one and past offers survive restarts.
- **Usage per account:** limits and resets are tracked for each account separately, and a window whose reset has passed reads Refreshed.
- **Claude Design sign-in** is machine-wide, and is shown as signed in only after the operation that needed it works.
- **Save your workspace to its repo.** Save to repo writes the workspace's sites, services, flows, processes, tabs and agents into the repository and shows you the changes first.
- **A clone comes back whole.** Opening a fresh clone restores what was saved. A trust step shows what the clone would run before anything starts. Flows arrive switched off and processes stay stopped until you start them.
- **Teammates' changes are offered, never applied by themselves.** When the repo brings new workspace settings, Genie offers them and you choose what to apply.
- **Rate limits no longer dump running work.** A flow lane or turn that hits a limit pauses and resumes where it stopped when the window resets or you switch accounts.
- **Rate-limit alerts:** add alerts at the thresholds you choose, each with its own sound.
- **Who is talking to whom, on the Dashboard.** Hover an agent's Comms icon to see flight-path arcs to the agents it is talking to, instead of a tangle of dashed lines.
- **Remote sessions:** the machine being reached shows who is connected and notifies on each arrival. Questions from that machine open in the Pilot's question window and are answered there. The remote banner no longer sits under the window buttons.
- **Plan nudges work again.** An agent with an open plan is nudged again after it makes progress or after you send a message. A turn Genie restarted is no longer treated as your Stop.
- **Storage:** a workspace Storage tab shows what takes space, moves clutter such as old worktrees and test results to .trash, and empties .trash only after you approve. Emptying it works reliably on Windows.
- **Playwright is managed by Genie:** one browser install serves every workspace and worktree, so nothing is installed per worktree.
- **Word wrap in the Files editor:** a wrapped line keeps one line number instead of looking like a new line.
- **Copied code keeps its ids.** Internal ids stay hidden in chat, but code and commands you copy are left exactly as written.
- **Agents sidebar:** follows the Dashboard's status filter, scrolls, and its Terminal and Files buttons open windows.
- **Cleaner screens.** Confirmations such as "Saved" pop up beside the button and go away, so nothing on the page jumps. The workspace and the agent view share one header. The agent's own Files tab is gone (use the workspace's Files), and the workspace header no longer lists repos or agent pills.
- **The agent pulse** replaces the lane bar: each agent tab shows its last minute of activity, with marks for edits, mail and questions.
- **Spell check and right-click menus** in every text field, the chat and the file viewer, with suggestions, Add to dictionary, and Cut, Copy and Paste.
- **Attaching files:** the composer tells you when you add a file over the per-message limit, and a message that failed to send no longer blocks the next one.
- **Files editor:** clicking below the last line puts the cursor at the end of the file.
- **Terminals:** after Paste (or Copy, Select all or Clear) from a terminal's right-click menu, typing goes to the terminal again.
- **Also:** approvals show as toasts on the left, and the Deck is now part of the Dashboard. Slash commands like /compact work in chat. Hover "Working · Plan" to see the open plan items. Running flows show as header pills. The Dashboard opens Terminal or Files windows for an agent's workspace. Toolchain has a PHP and Node version picker and a "Check for updates" button, and updating Claude Code updates the Claude your agents run. Sounds are picked with a play button each. Turning off Do Not Disturb opens the questions that waited. ArtBoard is its own workspace tab. The Tynn tab's work view updates live. Question previews show images. Settings → Agent MCP is a compact list. The site bar fits on one row. A terminal an agent opens for you is shown to you. An upgrade no longer closes Genie without installing.
