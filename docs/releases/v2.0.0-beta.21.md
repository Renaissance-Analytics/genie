# Genie 2.0.0-beta.21

## What's new

- **Genie's tools reach your agents.** Since Genie 2 began, Claude Code connected to Genie's MCP and then dropped every
  Genie tool — `imDone`, `ForceTheQuestion`, `agentinbox`, `knowledge`, `lists` and the rest — because one field in
  their published schema was the wrong shape for the MCP specification. Fixed: agents started by Genie now have them.
  Agents already running keep their old tool list until they are restarted.
- **The chat thread scrolls.** A long conversation in the chat flyout can be scrolled back to its start; the thread
  follows new messages only while you are at the end.
- **The chat flyout can be resized.** Drag its left edge (or use the arrow keys on it). The width is remembered
  across closing, pinning and restarts. Pinned chat keeps its designed width.
- **Tool rows say what they ran.** The Stream shows `Bash  npm test`, `Read  src/app.ts`, `Grep  pattern` — not just
  the tool's name. An edit row shows the file it edited.
- **Check for updates.** Settings → General has a *Check for updates* button with a status line, and the tray menu
  has *Check for updates*. Genie also checks on its own every 30 minutes (was every 4 hours).

## Migration

Installs over any earlier Genie in place, through the app's updater or the installer. Nothing to do: workspace agent
files are rewritten on first boot as before. Restart an agent to give it Genie's tools.

## Known limitations

- **Claude's reasoning text is not shown.** Current Claude models send their thinking blocks with the text omitted,
  and Claude Code has no documented setting to ask for the summarised text in the mode Genie uses, so the Stream says
  "Reasoning not sent by the provider".
- **GApps and agents-in-TUIs are not in this build** (the owner's ruling).
- **Attachments in the composer are not sent yet** (prism-acp-ts#4).
- Windows and Linux only; no macOS build.

## How it was verified

- **Every change went red → green** in a Linux test machine (WSL2), never on a developer's desktop.
- **The MCP fix was measured against the real Claude Code** before it was written: with the old schema Claude
  listed no Genie tool and logged why; with the corrected one it listed and called them, and Genie knew which
  agent was calling.
- **The Windows VM** builds the installer, installs it, and drives the installed app.
