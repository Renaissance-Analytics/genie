## What’s new

- After Genie updates itself, your agents get their `genie` tools back on their own. The upgrade notice used to arrive first and ask them to use tools whose connection had died with the old process — so the tools looked broken when they were only disconnected. The repair now goes first, and differs per harness: Claude Code takes the reconnect command, Codex gets a managed restart, because it has no reconnect command and cannot discover the new address on its own.
- Genie no longer types into a terminal that is sitting on a prompt. A TUI parked on its own dialog — Codex's "Update available… 1. Update now  2. Skip" — prints nothing, which every idle check read as "safe to type". It is not: the text lands as the answer, and on that particular screen the first option starts a global install.
- The driver control in an agent's panel now appears. Switching the TUI an agent runs under, and seeing its sidecars, was built and reachable from nowhere.
- Your workspace icon and your agents' avatars can be set. Pick any emoji, or clear it to go back to the workspace's initials and the TUI's own logo.
- The workspace row's controls are square, matching the agent avatars beside them instead of sitting as wide lozenges in a line of boxes.
- The Genie TUI launches again — it was looking for a `genie-tui` binary that does not exist.
- The guide says more about what sidecars are for: second opinions, a cold read from a driver that has none of the conversation's history, reaching a tool only one harness ships, watching a slow build, rehearsing something risky. They are examples, not a list of supported uses.
