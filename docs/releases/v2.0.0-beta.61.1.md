# Genie 2.0.0-beta.61.1


**A hotfix for beta.61: your host picker and trusted workspaces are back, new agents start again, and the fixes reported since beta.61 shipped. Please update.**


## Fixed

- **Your host picker is back.** A Pilot's title bar shows its host picker again; Genie shows the role Tynn reports, asks Tynn again when it can't tell, and says in words why it won't connect when it won't.
- **Your trusted workspaces stay trusted.** Trust carried over from before beta.61 is kept, and nothing a workspace adds or changes un-trusts it. An approval card that only asks because a workspace isn't trusted offers "Trust this workspace", and Allow/Deny stay in view. Workspace Settings has Untrust.
- **New agents start again.** Genie's background host is made with its process supervisor, and a new agent's model list is asked of the host.
- **Genie's own instructions are no longer drawn in an agent's chat.** One line says they were sent.
- **Importing a workspace from Tynn is never silent.** After you pick the folder you see progress, then the plan, or the failure in words with Try again.
- **Mail from Genie names Genie**, not an id, in the chat, the Deck and the inbox.
- **The Deck's "host copy" item is readable,** with one plain sentence, the detail folded away, and Try again / Open the log.
- **A stuck queue after a rate limit:** Stop is always there while a turn is open, a lifted limit or an account change sends what you queued, and a long-silent turn offers "Send now".
- **Enter sends, Shift+Enter is a new line.** Set the key in Settings → Keyboard by pressing it.
- **An agent's Skills page is readable,** grouped and searchable, and **MCP servers can be switched off per agent**, with a workspace default agents inherit.
- **Genie checks each agent CLI really runs** (not just that a file exists), names what's wrong ("not signed in" vs broken), and shows it on the Toolchain page.
- **A slow first start no longer leaves an empty window.** Genie waits for its own host, shows "Starting Genie's host…", and from 60 s offers Open the log and Restart.

## Known limitations

- **A terminal can stop drawing** if you type at the very moment its shell starts: what you type reaches the shell, but the pane doesn't show it. Close and reopen the terminal. The cause is located; the fix ships in 61.2.
- **Interrupting an agent can stop it and leave your queued messages "Not delivered"** when it is waiting on a long Genie tool call. Press Restart on the last message to send them. Fixed in 61.2.
- **A broken Claude or Codex install is detected and named, not yet repaired from Genie.** Reinstall it with the vendor's installer for now.

## Not in this build

- **Interrupt still stops the agent and leaves your queued messages "Not delivered"** (fix built, ships as 61.2).
- **Repairing a broken Claude/Codex CLI from Genie:** the native installer, a Repair button, Start offering the repair, and the Toolchain page's Update buttons (61.2 / 62). This build only detects and names the problem.
- **Commands an agent runs through Genie's services tool are still invisible** (no shell, no Stop) (62).
- **A terminal can intermittently stop drawing** if you type at the exact moment its shell starts (found by the new Linux gate; cause being traced).
- **The send button's tooltip still says Ctrl+Enter** (react-fancy 6.20 fixes it; 62).
- **Skills switches, per-tool MCP switches and per-plugin switches** (62; need prism-acp 0.42).
- **Several accounts per provider, the approval-card redesign, the upgrade waiting for agents' thumbs-up** (62).
- macOS.
