## What's new

- **"Check for updates" finds updates.** Every Genie release is a prerelease, and the updater skipped every one of them — so this is the first build that can offer you the next one.
- **Agents still never run in terminals** (from beta.3): the pty is gone as an agent engine, and the restart path that typed a launch line every time is closed.

## Migration

- This is the last install you have to download by hand. From here, Update in-app offers the next release.
